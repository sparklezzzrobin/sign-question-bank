## 使用与阅读建议
1. **编辑器支持**：推荐使用 Obsidian、Typora、VS Code (Markdown All in One) 打开本资料库，所有公式与图像相对链接即可原生渲染。
2. **刷题建议**：初期建议采用“按专题模块编排”进行纵向考点攻坚，后期采用“按年份编排”进行全卷模拟训练。
