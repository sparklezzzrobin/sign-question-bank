# 专题刷题库 ｜ 武大 807/936 信号与系统·按题型刷题系统

这是 `按年份编排` 与 `按专题模块编排` 之外的**第三套视图**：把全部真题按"专题 → 题型小节"重新编排，同类型题目放在一起刷。题目文字逐题搬运自年份卷与《936 真题题库》存档，公式已全部修复 / 还原，**图片不内嵌**——每题只标注原图切片路径或题库图床链接，看图请对照原卷 PDF（链接见文末总表）。

## 使用方法

1. 打开任一专题文件，先看顶部"考频总览"表了解该专题的出题密度与题型分布；
2. 进入题型小节，读"套路"行 → 看题干 → **自己完整做一遍** → 点开"展开解析"折叠块对答案；
3. 标 △ 的题目只有题干（2013~2017 年题库未附解析），解析请对照题库 PDF / 原卷；2018、2020 及 2022~2026 的解析已基本收齐；每题的"出处"链接可跳回年份卷原文。

## 数据来源与已知限制（诚实说明）

* **2013~2021 的题干**：转录自《信号与系统题库（含答案）》知乎存档（`pdf/信号与系统题库（含部分答案）.html`），其中 503 条 LaTeX 公式已从存档源码中完整还原；该存档里 2020、2018 两卷附有原博主的解答步骤，已一并收录（卡片内注明"题库原解答"），其余年份题库未附解析，卡片标 △。
* **存档缺损**：题库存档保存时丢了部分图与少量条件，凡缺图的卡片均注明"未随存档保留"；个别缺损条件（如 2015 年第 1 题分段式、2018 年第 10 题参数范围）按教材惯例复原并就地标注。
* **2022~2026**：题干与解析来自年份卷 Markdown；年份卷缺解析的题（2022 六 / 八 / 九 / 十，2023 五(2) / 七 / 十 / 十二，2026 除一 / 八外全部）已从 `pdf/` 文件夹的答案卷扫描件中逐页视觉转录补全，卡片中注明"答案卷原解答"。
* **图片**：全部不内嵌。2022~2025 每题标注 `images/` 切片路径；2025 年卷的 6 个切片（q4 / q6 / q7 / q8 / q9 / q11）在原库中缺失；2021 / 2020 / 2018 的图给出题库知乎图床直链，可直接点击查看。

## 设计决策记录（方便日后调整）

1. **专题骨架沿用指导文件六大模块**，分类码（1.1.1、3.3.1 等）与其一致；按题量增补了 1.4 / 1.5 / 4.4 / 4.5 / 5.3.2 / 6.3 六个新小节（指导文件未覆盖但真题反复考的板块）。
2. **主分类唯一＋参见**：一道题只归入一个主要考点小节，跨考点时在关联小节放 🔗 参见行，无重复副本。
3. **细分深度按题量决定**：题量支撑得起才独立成小节（如 3.3.1 冲激抽样、5.1.1 差分方程），孤题并入上级小节。
4. **解析折叠**：所有解析放在 `<details>` 折叠块内，先做后看。
5. **公式修复**：原年份卷存在批量 LaTeX 转义损坏（`\frac`→`rac` 等，130+ 处），本系统已全部还原；题库存档的公式从 MathJax 源码无损提取，作者笔误 `\infin` 已统一为 `\infty`。
6. **判断 / 填空题拆分**：2023 年第 1、2 题原文把答案直接写在题干里，本系统将题干与答案拆开（答案进折叠解析），内容一字未删。
