#### 讲义 18-1 ｜ 傅里叶变换时频对称性与积分性质对偶公式证明
> **专题** 3
> **归类** 3.1 傅里叶变换性质综合运算
> **出处** 27强化讲义 专题十八题目 第1题
> **页码** 242
> **答案页** 1

**题干**

已知 $\int_{-\infty}^t x(\tau)\mathrm{d}\tau$ 的傅里叶变换为 $\dfrac{1}{\mathrm{j}\omega}X(\mathrm{j}\omega) + \pi X(0)\delta(\omega)$，试证明 $\dfrac{x(t)}{-\mathrm{j}t} + \pi x(0)\delta(t)$ 的傅里叶变换为 $\int_{-\infty}^\omega X(\mathrm{j}\tau)\mathrm{d}\tau$。  

<details><summary>📖 解答</summary>

**证明过程：**

**1. 利用傅里叶变换的对偶性（对称性质）：**
- 若时域信号 $x(t)$ 与频域函数 $X(\mathrm{j}\omega)$ 满足傅里叶变换对：
  $$\mathcal{F}[x(t)] = X(\mathrm{j}\omega)$$
  则根据对称性质（Duality Property），将时域变量代换为频域函数形式，有：
  $$\mathcal{F}[X(\mathrm{j}t)] = 2\pi x(-\omega)$$

**2. 作用于已知积分性质对偶：**
- 令已知积分信号为时域函数：
  $$g(t) = \int_{-\infty}^t x(\tau)\mathrm{d}\tau$$
  其傅里叶变换为：
  $$G(\mathrm{j}\omega) = \frac{1}{\mathrm{j}\omega}X(\mathrm{j}\omega) + \pi X(0)\delta(\omega)$$
- 根据对偶性质，以 $G(\mathrm{j}t)$ 为时域函数，其傅里叶变换必满足：
  $$\mathcal{F}[G(\mathrm{j}t)] = 2\pi g(-\omega)$$
  将 $G(\mathrm{j}t)$ 表达式代入：
  $$\mathcal{F}\left[ \frac{1}{\mathrm{j}t}X(\mathrm{j}t) + \pi X(0)\delta(t) \right] = 2\pi \int_{-\infty}^{-\omega} x(\tau)\mathrm{d}\tau$$

**3. 利用线性性质与反转性质：**
- 交换符号与变量：利用频域反转对偶关系，若 $f(t) \leftrightarrow F(\omega)$，则 $f(-t) \leftrightarrow F(-\omega)$。
  针对信号 $x(t)$ 本身，若考虑逆变换的对称形式：
  时频对偶在积分定义下的标准形式为：
  $$\mathcal{F}\left[\frac{x(t)}{-\mathrm{j}t} + \pi x(0)\delta(t)\right]$$
  直接由频域积分性质：
  频域微分对应时域乘以 $(-\mathrm{j}t)$：$x(t) \leftrightarrow X(\mathrm{j}\omega) \implies -\mathrm{j}t x(t) \leftrightarrow \frac{\mathrm{d}X(\mathrm{j}\omega)}{\mathrm{d}\omega}$。
  对偶地，频域积分对应时域除以 $(-\mathrm{j}t)$ 加上直流冲激项：
  $$\mathcal{F}\left[ \frac{x(t)}{-\mathrm{j}t} + \pi x(0)\delta(t) \right] = \int_{-\infty}^\omega X(\mathrm{j}\tau)\mathrm{d}\tau$$
  原式获证。

</details>

#### 讲义 18-2 ｜ 泊松求和公式证明及其级数求和应用
> **专题** 3
> **归类** 3.3 抽样定理与无失真恢复系统
> **出处** 27强化讲义 专题十八题目 第2题
> **页码** 242
> **答案页** 1

**题干**

(1) 证明等式 $\sum_{n=-\infty}^\infty x(t + nT) = \dfrac{1}{T} \sum_{k=-\infty}^\infty X(k\omega_0) e^{\mathrm{j}k\omega_0 t}$，其中 $X(\omega)$ 是 $x(t)$ 的傅里叶变换，$\omega_0 = \dfrac{2\pi}{T}$；  
(2) 证明等式 $\sum_{n=-\infty}^\infty e^{-a|n|} = \sum_{k=-\infty}^\infty \dfrac{2a}{a^2 + (2\pi k)^2}$，其中 $a > 0$；  
(3) 求级数 $\sum_{k=-\infty}^\infty \dfrac{1}{1 + k^2}$ 的和。  

<details><summary>📖 解答</summary>

**1. 证明泊松求和公式 (1)：**
- 记周期化信号为 $x_p(t) = \sum_{n=-\infty}^\infty x(t + nT) = x(t) * \sum_{n=-\infty}^\infty \delta(t + nT)$。
- 周期冲激串的傅里叶级数展开式为：
  $$\sum_{n=-\infty}^\infty \delta(t + nT) = \frac{1}{T} \sum_{k=-\infty}^\infty e^{\mathrm{j} k \omega_0 t}, \quad \omega_0 = \frac{2\pi}{T}$$
- 因此时域卷积为：
  $$x_p(t) = x(t) * \left[ \frac{1}{T} \sum_{k=-\infty}^\infty e^{\mathrm{j} k \omega_0 t} \right] = \frac{1}{T} \sum_{k=-\infty}^\infty \left[ x(t) * e^{\mathrm{j} k \omega_0 t} \right]$$
- 根据复指数信号通过 LTI 系统的特征函数性质（或直接写出卷积积分）：
  $$x(t) * e^{\mathrm{j} k \omega_0 t} = \int_{-\infty}^\infty x(\tau) e^{\mathrm{j} k \omega_0 (t - \tau)} \mathrm{d}\tau = e^{\mathrm{j} k \omega_0 t} \int_{-\infty}^\infty x(\tau) e^{-\mathrm{j} k \omega_0 \tau} \mathrm{d}\tau = X(k\omega_0) e^{\mathrm{j} k \omega_0 t}$$
- 代入即得：
  $$\sum_{n=-\infty}^\infty x(t + nT) = \frac{1}{T} \sum_{k=-\infty}^\infty X(k\omega_0) e^{\mathrm{j} k \omega_0 t}$$
  第 (1) 问获证。

**2. 证明等式 (2)：**
- 构造连续双边指数衰减信号 $x_1(t) = e^{-a|t|}$（$a > 0$）。
- 其傅里叶变换为双边对称指数积分：
  $$X_1(\omega) = \int_{-\infty}^\infty e^{-a|t|} e^{-\mathrm{j}\omega t}\mathrm{d}t = \frac{2a}{a^2 + \omega^2}$$
- 取周期 $T = 1$，则 $\omega_0 = \frac{2\pi}{T} = 2\pi$。
- 将 $x_1(t)$ 代入 (1) 式的泊松求和公式中，并令时间 $t = 0$：
  - 左端：
    $$\left. \sum_{n=-\infty}^\infty x_1(t + nT) \right|_{t=0} = \sum_{n=-\infty}^\infty x_1(n) = \sum_{n=-\infty}^\infty e^{-a|n|}$$
  - 右端：
    $$\left. \frac{1}{1} \sum_{k=-\infty}^\infty X_1(k\omega_0) e^{\mathrm{j} k \omega_0 t} \right|_{t=0} = \sum_{k=-\infty}^\infty X_1(2\pi k) = \sum_{k=-\infty}^\infty \frac{2a}{a^2 + (2\pi k)^2}$$
- 左右两端恒等，第 (2) 问获证。

**3. 求级数 $\sum_{k=-\infty}^\infty \dfrac{1}{1 + k^2}$ 的和：**
- 在第 (2) 问中，为了使右边分母变为 $1 + k^2$，可选取参数 $a = 2\pi$：
  代入 (2) 式得：
  $$\sum_{n=-\infty}^\infty e^{-2\pi|n|} = \sum_{k=-\infty}^\infty \frac{2(2\pi)}{(2\pi)^2 + (2\pi k)^2} = \sum_{k=-\infty}^\infty \frac{4\pi}{4\pi^2 (1 + k^2)} = \frac{1}{\pi} \sum_{k=-\infty}^\infty \frac{1}{1 + k^2}$$
- 因此：
  $$\sum_{k=-\infty}^\infty \frac{1}{1 + k^2} = \pi \sum_{n=-\infty}^\infty e^{-2\pi|n|}$$
- 计算左侧等比级数：
  $$\sum_{n=-\infty}^\infty e^{-2\pi|n|} = e^0 + 2 \sum_{n=1}^\infty (e^{-2\pi})^n = 1 + 2 \frac{e^{-2\pi}}{1 - e^{-2\pi}} = \frac{1 + e^{-2\pi}}{1 - e^{-2\pi}} = \coth(\pi)$$
- 从而求得级数和为：
  $$\sum_{k=-\infty}^\infty \frac{1}{1 + k^2} = \pi \frac{1 + e^{-2\pi}}{1 - e^{-2\pi}} = \pi \coth(\pi)$$

</details>

#### 讲义 18-3 ｜ 冲激函数高阶导数与幂函数相乘性质证明
> **专题** 1
> **归类** 1.5 冲激函数性质速算
> **出处** 27强化讲义 专题十八题目 第3题
> **页码** 243
> **答案页** 2

**题干**

证明：$t^n \delta^{(n)}(t) = (-1)^n n! \delta(t)$  

<details><summary>📖 解答</summary>

**方法一：数学归纳法**

- **基础步**：当 $n = 1$ 时：
  由冲激函数的导数乘积微分法则：
  $$t \delta'(t) = [t\delta(t)]' - (t)' \delta(t) = 0 - \delta(t) = -\delta(t) = (-1)^1 1! \delta(t)$$
  结论成立。

- **归纳假设**：设当 $n = k$ 时等式成立，即：
  $$t^k \delta^{(k)}(t) = (-1)^k k! \delta(t)$$

- **递推证明**：考虑 $n = k + 1$ 的情形：
  对归纳假设等式两端关于 $t$ 求导：
  $$\frac{\mathrm{d}}{\mathrm{d}t} \big[ t^k \delta^{(k)}(t) \big] = \frac{\mathrm{d}}{\mathrm{d}t} \big[ (-1)^k k! \delta(t) \big]$$
  展开左端导数：
  $$k t^{k-1} \delta^{(k)}(t) + t^k \delta^{(k+1)}(t) = (-1)^k k! \delta'(t)$$
  两端同乘以 $t$：
  $$k t^k \delta^{(k)}(t) + t^{k+1} \delta^{(k+1)}(t) = (-1)^k k! [t \delta'(t)]$$
  将归纳假设 $t^k \delta^{(k)}(t) = (-1)^k k! \delta(t)$ 以及 $t \delta'(t) = -\delta(t)$ 代入：
  $$k [(-1)^k k! \delta(t)] + t^{k+1} \delta^{(k+1)}(t) = (-1)^k k! [-\delta(t)] = (-1)^{k+1} k! \delta(t)$$
  移项整理：
  $$t^{k+1} \delta^{(k+1)}(t) = (-1)^{k+1} k! \delta(t) - k (-1)^k k! \delta(t)$$
  提取公因式 $(-1)^{k+1} k! \delta(t)$：
  $$t^{k+1} \delta^{(k+1)}(t) = (-1)^{k+1} k! (1 + k) \delta(t) = (-1)^{k+1} (k+1)! \delta(t)$$
  结论对 $n = k+1$ 也成立。
  由数学归纳法可知，等式对任意自然数 $n \in \mathbb{N}^+$ 均成立。

---

**方法二：拉普拉斯变换频域证明法**

- 已知单位冲激信号的拉氏变换为 $\mathcal{L}[\delta(t)] = 1$。
- 根据频域微分性质 $\mathcal{L}[t^n f(t)] = (-1)^n \dfrac{\mathrm{d}^n}{\mathrm{d}s^n} F(s)$：
  $$\mathcal{L}[\delta^{(n)}(t)] = s^n$$
  $$\mathcal{L}[t^n \delta^{(n)}(t)] = (-1)^n \frac{\mathrm{d}^n}{\mathrm{d}s^n}(s^n) = (-1)^n n!$$
- 对常数 $(-1)^n n!$ 取拉氏逆变换，直接得到时域信号：
  $$\mathcal{L}^{-1}\big[ (-1)^n n! \big] = (-1)^n n! \delta(t)$$
- 故 $t^n \delta^{(n)}(t) = (-1)^n n! \delta(t)$ 获证。

</details>

#### 讲义 18-4 ｜ 余弦调制周期信号的傅里叶级数复系数证明
> **专题** 3
> **归类** 3.4 周期信号傅里叶级数与稳态频响
> **出处** 27强化讲义 专题十八题目 第4题
> **页码** 244
> **答案页** 3

**题干**

设周期信号 $f(t)$ 和 $f_1(t)$ 的傅里叶复系数分别为 $F_m$ 和 $F_{1,m}$，其中 $\omega_0$ 是 $f(t)$ 的基波角频率，$f_1(t) = f(t)\cos(\omega_0 t)$，试证明 $F_{1,m} = \dfrac{1}{2}(F_{m-1} + F_{m+1})$。  

<details><summary>📖 解答</summary>

**证明过程：**

- 由指数形式傅里叶级数定义，$f(t)$ 的展开式为：
  $$f(t) = \sum_{k=-\infty}^\infty F_k e^{\mathrm{j}k\omega_0 t}$$
  其中复系数为：
  $$F_m = \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-\mathrm{j}m\omega_0 t}\mathrm{d}t \quad \left(T = \frac{2\pi}{\omega_0}\right)$$
- 调制信号 $f_1(t) = f(t)\cos(\omega_0 t)$。利用欧拉公式展开余弦项：
  $$\cos(\omega_0 t) = \frac{1}{2}\left(e^{\mathrm{j}\omega_0 t} + e^{-\mathrm{j}\omega_0 t}\right)$$
- 将展开式代入 $f_1(t)$ 的复傅里叶系数定义式：
  $$F_{1,m} = \frac{1}{T} \int_{-T/2}^{T/2} f_1(t) e^{-\mathrm{j}m\omega_0 t}\mathrm{d}t = \frac{1}{T} \int_{-T/2}^{T/2} f(t) \cdot \frac{1}{2}\left(e^{\mathrm{j}\omega_0 t} + e^{-\mathrm{j}\omega_0 t}\right) e^{-\mathrm{j}m\omega_0 t}\mathrm{d}t$$
  拆分为两项积分：
  $$F_{1,m} = \frac{1}{2} \left[ \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-\mathrm{j}(m-1)\omega_0 t}\mathrm{d}t + \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-\mathrm{j}(m+1)\omega_0 t}\mathrm{d}t \right]$$
- 根据原信号傅里叶系数的定义，第一项积分即为 $F_{m-1}$，第二项积分即为 $F_{m+1}$：
  $$F_{1,m} = \frac{1}{2}\big(F_{m-1} + F_{m+1}\big)$$
- 原式获证。

</details>

#### 讲义 18-5 ｜ 降采样抽取序列的 z 变换表达式推导
> **专题** 5
> **归类** 5.1 差分方程求解与离散全响应
> **出处** 27强化讲义 专题十八题目 第5题
> **页码** 244
> **答案页** 3

**题干**

已知序列 $x(n)$ 的 $z$ 变换是 $X(z)$，$y(n) = x(2n)$，求 $Y(z)$。  

<details><summary>📖 解答</summary>

**求解推导过程：**

- 根据 $z$ 变换的定义，抽取序列 $y(n)$ 的 $z$ 变换为：
  $$Y(z) = \sum_{n=-\infty}^\infty y(n) z^{-n} = \sum_{n=-\infty}^\infty x(2n) z^{-n}$$
- 为了将其与原序列 $X(z)$ 建立联系，构造仅保留偶数样点的辅助序列 $x_e(m)$：
  $$x_e(m) = \begin{cases} x(m), & m \text{ 为偶数} \\ 0, & m \text{ 为奇数} \end{cases}$$
  利用离散单位梳状因子，偶数判定可表示为：
  $$x_e(m) = x(m) \cdot \frac{1 + (-1)^m}{2} = \frac{1}{2} x(m) + \frac{1}{2} (-1)^m x(m)$$
- 观察 $Y(z)$ 与 $x_e(m)$ 的关系：
  令 $m = 2n$（$n = m/2$），则：
  $$Y(z) = \sum_{m \text{ 为偶数}} x(m) z^{-m/2} = \sum_{m=-\infty}^\infty x_e(m) \left(z^{1/2}\right)^{-m}$$
- 将 $x_e(m)$ 的表达式代入：
  $$Y(z) = \sum_{m=-\infty}^\infty \left[ \frac{1}{2} x(m) + \frac{1}{2} (-1)^m x(m) \right] \left(z^{1/2}\right)^{-m}$$
  拆分为两项求和：
  $$Y(z) = \frac{1}{2} \sum_{m=-\infty}^\infty x(m) \left(z^{1/2}\right)^{-m} + \frac{1}{2} \sum_{m=-\infty}^\infty x(m) \left(-z^{1/2}\right)^{-m}$$
- 由 $z$ 变换定义 $\sum_{m=-\infty}^\infty x(m) u^{-m} = X(u)$，分别代入 $u = z^{1/2}$ 与 $u = -z^{1/2}$：
  $$Y(z) = \frac{1}{2} X\left(z^{1/2}\right) + \frac{1}{2} X\left(-z^{1/2}\right)$$

结论：
$$Y(z) = \frac{1}{2}\left[ X\left(z^{1/2}\right) + X\left(-z^{1/2}\right) \right]$$

</details>

#### 讲义 18-6 ｜ 奇函数信号与奇函数冲激响应卷积为偶函数证明
> **专题** 2
> **归类** 2.1 连续卷积积分与零状态响应
> **出处** 27强化讲义 专题十八题目 第6题
> **页码** 245
> **答案页** 4

**题干**

证明：如果 $x(t)$ 和 $h(t)$ 是奇函数，则 $y(t) = x(t)*h(t)$ 是偶函数。  

<details><summary>📖 解答</summary>

**证明过程：**

- 根据连续时间卷积积分的定义：
  $$y(t) = \int_{-\infty}^\infty x(\tau) h(t - \tau) \mathrm{d}\tau$$
- 计算 $y(-t)$：
  $$y(-t) = \int_{-\infty}^\infty x(\tau) h(-t - \tau) \mathrm{d}\tau$$
- 因为 $x(t)$ 和 $h(t)$ 均为奇函数，满足奇函数对称性：
  $$x(-\tau) = -x(\tau), \quad h(-u) = -h(u)$$
- 在 $y(-t)$ 的积分中引入换元：令 $\tau = -\lambda$，则 $\mathrm{d}\tau = -\mathrm{d}\lambda$：
  - 积分下限 $\tau = -\infty \implies \lambda = +\infty$；
  - 积分上限 $\tau = +\infty \implies \lambda = -\infty$。
  代入得：
  $$y(-t) = \int_{+\infty}^{-\infty} x(-\lambda) h(-t + \lambda) (-\mathrm{d}\lambda) = \int_{-\infty}^\infty x(-\lambda) h(\lambda - t) \mathrm{d}\lambda$$
- 利用 $x(-\lambda) = -x(\lambda)$ 及 $h(\lambda - t) = -h(t - \lambda)$：
  $$x(-\lambda) h(\lambda - t) = [-x(\lambda)][-h(t - \lambda)] = x(\lambda) h(t - \lambda)$$
- 代回积分式：
  $$y(-t) = \int_{-\infty}^\infty x(\lambda) h(t - \lambda) \mathrm{d}\lambda = y(t)$$
- 满足偶函数定义 $y(-t) = y(t)$，因此 $y(t)$ 是偶函数，命题获证。

</details>

#### 讲义 18-7 ｜ 因果实信号傅里叶变换实部双重积分恒等式证明
> **专题** 3
> **归类** 3.2 单边带调制 (SSB) 与希尔伯特变换（武大必考王牌）
> **出处** 27强化讲义 专题十八题目 第7题
> **页码** 245
> **答案页** 5

**题干**

设实因果信号 $f(t) \leftrightarrow F(\omega) = R(\omega) + \mathrm{j}X(\omega)$，且 $f_e(t)$ 为 $f(t)$ 的偶分量。  
(1) 证明：$f_e(t) \leftrightarrow R(\omega)$  
(2) 证明：$R(\omega) = \dfrac{2}{\pi}\int_0^\infty \int_0^\infty R(y)\cos(yt)\cos(\omega t)\mathrm{d}y\mathrm{d}t$  

<details><summary>📖 解答</summary>

**1. 证明 (1) $f_e(t) \leftrightarrow R(\omega)$：**
- 信号 $f(t)$ 的偶分量定义为：
  $$f_e(t) = \frac{f(t) + f(-t)}{2}$$
- 对上式两端取傅里叶变换，根据线性性质与时域反转性质（$\mathcal{F}[f(-t)] = F(-\omega)$）：
  $$\mathcal{F}[f_e(t)] = \frac{F(\omega) + F(-\omega)}{2}$$
- 因为 $f(t)$ 为实信号，其傅里叶变换具有共轭对称性：
  $$F(-\omega) = F^*(\omega) = R(\omega) - \mathrm{j}X(\omega)$$
- 代入得：
  $$\mathcal{F}[f_e(t)] = \frac{[R(\omega) + \mathrm{j}X(\omega)] + [R(\omega) - \mathrm{j}X(\omega)]}{2} = R(\omega)$$
  第 (1) 问获证。

**2. 证明 (2) 双重积分恒等式：**
- 由第 (1) 问可知，$f_e(t)$ 为实偶信号，其频域变换 $R(\omega)$ 也是实偶函数。
- 对实偶信号 $f_e(t)$ 列写傅里叶变换与逆变换公式：
  - 正变换（由 $f_e(t)$ 实且偶）：
    $$R(\omega) = \int_{-\infty}^\infty f_e(t) e^{-\mathrm{j}\omega t}\mathrm{d}t = 2 \int_0^\infty f_e(t) \cos(\omega t)\mathrm{d}t \quad \text{①}$$
  - 逆变换（由 $R(y)$ 实且偶）：
    $$f_e(t) = \frac{1}{2\pi} \int_{-\infty}^\infty R(y) e^{\mathrm{j}y t}\mathrm{d}y = \frac{1}{\pi} \int_0^\infty R(y) \cos(y t)\mathrm{d}y \quad \text{②}$$
- 将式 ② 中的 $f_e(t)$ 表达式直接代入式 ① 中：
  $$R(\omega) = 2 \int_0^\infty \left[ \frac{1}{\pi} \int_0^\infty R(y)\cos(yt)\mathrm{d}y \right] \cos(\omega t)\mathrm{d}t$$
- 提出常数因数 $\dfrac{2}{\pi}$：
  $$R(\omega) = \frac{2}{\pi} \int_0^\infty \int_0^\infty R(y)\cos(yt)\cos(\omega t)\mathrm{d}y\mathrm{d}t$$
  第 (2) 问获证。

</details>

#### 讲义 18-8 ｜ 实周期信号傅里叶级数时移、尺度与对称性质综合证明
> **专题** 3

> **出处** 27强化讲义 专题十八题目 第8题
> **页码** 246
> **答案页** 6

**题干**

对于周期为 $T$ 的实周期信号 $f(t)$，考虑复指数形式的傅里叶级数，即：
$$f(t) = \sum_{n=-\infty}^\infty F_n e^{\mathrm{j}n\omega_1 t}, \quad \omega_1 = \frac{2\pi}{T}$$
其中 $F_n = \dfrac{1}{T}\int_{-T/2}^{T/2} f(t)e^{-\mathrm{j}n\omega_1 t}\mathrm{d}t$。试证明：  
(1) 设 $f_1(t) = f(t-t_0)$，这里 $t_0$ 是实常数，$f_1(t) = \sum_{n=-\infty}^\infty F_{1,n} e^{\mathrm{j}n\omega_1 t}$，则 $F_{1,n} = e^{-\mathrm{j}n\omega_1 t_0} F_n$；  
(2) 设 $f_2(t) = f(\alpha t)$，$\alpha$ 为实常数且 $\alpha > 0$，$f_2(t) = \sum_{n=-\infty}^\infty F_{2,n} e^{\mathrm{j}n\omega_2 t}$，则 $F_{2,n} = F_n$；  
(3) $F_{-n} = F_n^*$；  
(4) 若 $f(t)$ 关于 $t$ 实且偶，则 $F_n$ 关于 $n$ 实且偶；  
(5) 若 $f(t)$ 关于 $t$ 实且奇，则 $F_n$ 关于 $n$ 纯虚且奇。  

<details><summary>📖 解答</summary>

**证明过程：**

**1. 证明 (1) 时移性质：**
- 将 $f(t) = \sum_{n=-\infty}^\infty F_n e^{\mathrm{j}n\omega_1 t}$ 中的 $t$ 替换为 $t - t_0$：
  $$f_1(t) = f(t - t_0) = \sum_{n=-\infty}^\infty F_n e^{\mathrm{j}n\omega_1 (t - t_0)} = \sum_{n=-\infty}^\infty \big[ F_n e^{-\mathrm{j}n\omega_1 t_0} \big] e^{\mathrm{j}n\omega_1 t}$$
- 对比 $f_1(t)$ 的傅里叶级数展开式 $f_1(t) = \sum_{n=-\infty}^\infty F_{1,n} e^{\mathrm{j}n\omega_1 t}$，直接由展开系数的唯一性得到：
  $$F_{1,n} = e^{-\mathrm{j}n\omega_1 t_0} F_n$$

**2. 证明 (2) 尺度变换性质：**
- $f_2(t) = f(\alpha t)$ 的周期缩短为 $T_2 = \frac{T}{\alpha}$，基波角频率变为 $\omega_2 = \alpha \omega_1$。
- 将 $f(t)$ 的复指数展开式直接代入：
  $$f_2(t) = f(\alpha t) = \sum_{n=-\infty}^\infty F_n e^{\mathrm{j}n\omega_1 (\alpha t)} = \sum_{n=-\infty}^\infty F_n e^{\mathrm{j}n(\alpha \omega_1) t} = \sum_{n=-\infty}^\infty F_n e^{\mathrm{j}n\omega_2 t}$$
- 与定义式对比，各次谐波复系数完全不变：
  $$F_{2,n} = F_n$$

**3. 证明 (3) 共轭对称性：**
- 由系数积分公式：
  $$F_{-n} = \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-\mathrm{j}(-n)\omega_1 t}\mathrm{d}t = \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{\mathrm{j}n\omega_1 t}\mathrm{d}t$$
- 对 $F_n$ 取复共轭，由于 $f(t)$ 为实信号（$f^*(t) = f(t)$）：
  $$F_n^* = \left[ \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-\mathrm{j}n\omega_1 t}\mathrm{d}t \right]^* = \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{\mathrm{j}n\omega_1 t}\mathrm{d}t$$
- 故 $F_{-n} = F_n^*$。

**4. 证明 (4) 实偶信号对应实偶系数：**
- 由 $f(t) = f(-t)$，根据换元 $\tau = -t$：
  $$F_n = \frac{1}{T}\int_{-T/2}^{T/2} f(t)\cos(n\omega_1 t)\mathrm{d}t - \frac{\mathrm{j}}{T}\int_{-T/2}^{T/2} f(t)\sin(n\omega_1 t)\mathrm{d}t$$
- 偶函数乘以奇函数 $\sin(n\omega_1 t)$ 仍为奇函数，在对称区间 $[-T/2, T/2]$ 上的积分为零，故虚部为 0，$F_n$ 为实数。
- 结合 (3) 的结论 $F_{-n} = F_n^* = F_n$，故 $F_n$ 关于 $n$ 实且偶。

**5. 证明 (5) 实奇信号对应纯虚奇系数：**
- 由 $f(t) = -f(-t)$，偶函数 $\cos(n\omega_1 t)$ 与奇函数 $f(t)$ 相乘积分为零，实部为 0，故 $F_n$ 为纯虚数。
- 结合 (3) 的结论：记 $F_n = \mathrm{j} b_n$（$b_n$ 为实数），则 $F_n^* = -\mathrm{j} b_n = -F_n$。
  由 $F_{-n} = F_n^* = -F_n$，可知 $F_n$ 关于 $n$ 为奇函数。
- 故 $F_n$ 关于 $n$ 纯虚且奇。

</details>

#### 讲义 18-9 ｜ 希尔伯特变换冲激响应、二次变换反相与时域正交性证明
> **专题** 3
> **归类** 3.2 单边带调制 (SSB) 与希尔伯特变换（武大必考王牌）
> **出处** 27强化讲义 专题十八题目 第9题
> **页码** 247
> **答案页** 7

**题干**

令 $L[\cdot]$ 表示希尔伯特变换运算，$h(t)$ 为希尔伯特变换器的单位冲激响应，即有 $L[f(t)] = h(t)*f(t)$，若 $h(t)$ 的傅里叶变换为 $H(\omega) = -\mathrm{j}\operatorname{sgn}(\omega)$（讲义符号记为 $H(\omega) = \mathrm{j}\operatorname{sgn}(\omega)$），$f(t)$ 为实值信号。  
(1) 求 $h(t)$；  
(2) 证明：① $L\{L[f(t)]\} = -f(t)$；② $\int_{-\infty}^\infty f(t) L[f(t)] \mathrm{d}t = 0$。  

<details><summary>📖 解答</summary>

**1. 求解冲激响应 $h(t)$：**
- 依据讲义给定的频响定义 $H(\omega) = \mathrm{j}\operatorname{sgn}(\omega)$：
  已知经典傅里叶变换对：
  $$\frac{1}{\pi t} \longleftrightarrow -\mathrm{j}\operatorname{sgn}(\omega)$$
  因此对于 $H(\omega) = \mathrm{j}\operatorname{sgn}(\omega)$，其傅里叶逆变换为：
  $$h(t) = \mathcal{F}^{-1}[\mathrm{j}\operatorname{sgn}(\omega)] = -\frac{1}{\pi t}$$

**2. 证明 ① 希尔伯特二次级联反相性：**
- 二次级联变换的时域运算为卷积两次：
  $$L\{L[f(t)]\} = f(t) * h(t) * h(t)$$
- 对应频域等效传递函数为：
  $$H_{\text{total}}(\omega) = H(\omega) \cdot H(\omega) = [\mathrm{j}\operatorname{sgn}(\omega)]^2 = \mathrm{j}^2 [\operatorname{sgn}(\omega)]^2 = -1 \cdot 1 = -1 \quad (\forall \omega \ne 0)$$
- 频域中输出谱为：
  $$\mathcal{F}\big( L\{L[f(t)]\} \big) = -F(\omega)$$
- 取傅里叶逆变换即得：
  $$L\{L[f(t)]\} = -f(t)$$
  结论 ① 获证。

**3. 证明 ② 原信号与希尔伯特变换信号的时域正交性：**
- 利用频域帕塞瓦尔定理（Parseval's Theorem）：
  $$\int_{-\infty}^\infty f(t) g(t)\mathrm{d}t = \frac{1}{2\pi} \int_{-\infty}^\infty F(\omega) G^*(\omega)\mathrm{d}\omega$$
  此处令 $g(t) = L[f(t)]$，其傅里叶变换为 $G(\omega) = F(\omega) H(\omega) = F(\omega) [\mathrm{j}\operatorname{sgn}(\omega)]$。
- 代入帕塞瓦尔内积积分中：
  $$\int_{-\infty}^\infty f(t) L[f(t)]\mathrm{d}t = \frac{1}{2\pi} \int_{-\infty}^\infty F(\omega) \big( F(\omega) [\mathrm{j}\operatorname{sgn}(\omega)] \big)^* \mathrm{d}\omega$$
  由于 $[\mathrm{j}\operatorname{sgn}(\omega)]^* = -\mathrm{j}\operatorname{sgn}(\omega)$，且 $f(t)$ 为实信号满足 $F(\omega)F^*(\omega) = |F(\omega)|^2$：
  $$\int_{-\infty}^\infty f(t) L[f(t)]\mathrm{d}t = \frac{1}{2\pi} \int_{-\infty}^\infty |F(\omega)|^2 \big( -\mathrm{j}\operatorname{sgn}(\omega) \big) \mathrm{d}\omega = -\frac{\mathrm{j}}{2\pi} \int_{-\infty}^\infty |F(\omega)|^2 \operatorname{sgn}(\omega) \mathrm{d}\omega$$
- 分析被积函数奇偶性：
  - 幅度平方 $|F(\omega)|^2$ 是实偶函数；
  - 符号函数 $\operatorname{sgn}(\omega)$ 是奇函数；
  - 因此被积函数 $|F(\omega)|^2 \operatorname{sgn}(\omega)$ 是严格的**奇函数**！
- 奇函数在对称区间 $(-\infty, \infty)$ 上的积分恒等于零：
  $$\int_{-\infty}^\infty |F(\omega)|^2 \operatorname{sgn}(\omega) \mathrm{d}\omega = 0$$
- 故：
  $$\int_{-\infty}^\infty f(t) L[f(t)]\mathrm{d}t = 0$$
  结论 ② 获证。

</details>

#### 讲义 18-10 ｜ 带通载波调制信号与低通等效冲激响应卷积性质证明
> **专题** 3
> **归类** 3.2 单边带调制 (SSB) 与希尔伯特变换（武大必考王牌）
> **出处** 27强化讲义 专题十八题目 第10题
> **页码** 248
> **答案页** 8

**题干**

设 $f_L(t)$ 和 $h_L(t)$ 均为最高角频率不超过 $\omega_m$ 的带限信号，且载波角频率 $\omega_c \gg \omega_m$。若
$$f(t) = f_L(t)\cos(\omega_c t)$$
$$h(t) = 2h_L(t)\cos(\omega_c t)$$
且 $y_L(t) = f_L(t)*h_L(t)$，试证明：$y(t) = f(t)*h(t) = y_L(t)\cos(\omega_c t)$。  

<details><summary>📖 解答</summary>

**证明过程：**

**1. 求调制输入与冲激响应的傅里叶变换：**
- 设基带信号 $f_L(t) \leftrightarrow F_L(\omega)$，$h_L(t) \leftrightarrow H_L(\omega)$。
  由条件，两者的频谱均限制在低频带限范围 $[-\omega_m, \omega_m]$ 内，即当 $|\omega| > \omega_m$ 时，$F_L(\omega) = 0, H_L(\omega) = 0$。
- 根据频域调制（频移）性质：
  $$F(\omega) = \mathcal{F}[f_L(t)\cos(\omega_c t)] = \frac{1}{2}\big[ F_L(\omega - \omega_c) + F_L(\omega + \omega_c) \big]$$
  $$H(\omega) = \mathcal{F}[2h_L(t)\cos(\omega_c t)] = H_L(\omega - \omega_c) + H_L(\omega + \omega_c)$$

**2. 在频域计算卷积输出 $Y(\omega) = F(\omega) H(\omega)$：**
- 将两式相乘：
  $$Y(\omega) = \frac{1}{2}\big[ F_L(\omega - \omega_c) + F_L(\omega + \omega_c) \big] \big[ H_L(\omega - \omega_c) + H_L(\omega + \omega_c) \big]$$
  展开交叉乘积项：
  $$Y(\omega) = \frac{1}{2} F_L(\omega - \omega_c) H_L(\omega - \omega_c) + \frac{1}{2} F_L(\omega + \omega_c) H_L(\omega + \omega_c) + \frac{1}{2} F_L(\omega - \omega_c) H_L(\omega + \omega_c) + \frac{1}{2} F_L(\omega + \omega_c) H_L(\omega - \omega_c)$$

**3. 利用带限不重叠条件消除交叉项：**
- 考察两项交叉乘积：
  - 谱项 $F_L(\omega - \omega_c)$ 的有效频带集中在 $[\omega_c - \omega_m, \omega_c + \omega_m]$；
  - 谱项 $H_L(\omega + \omega_c)$ 的有效频带集中在 $[-\omega_c - \omega_m, -\omega_c + \omega_m]$。
- 因为载波频率远大于最高基带截止频率 $\omega_c \gg \omega_m$（即 $\omega_c - \omega_m > -\omega_c + \omega_m$，频带完全无交集）：
  $$F_L(\omega - \omega_c) H_L(\omega + \omega_c) = 0, \quad F_L(\omega + \omega_c) H_L(\omega - \omega_c) = 0$$
  交叉混叠项在整个频域恒等于零！

**4. 合成频域与时域结果：**
- 因此输出频谱简化为同频段项之和：
  $$Y(\omega) = \frac{1}{2} \big[ F_L(\omega - \omega_c) H_L(\omega - \omega_c) + F_L(\omega + \omega_c) H_L(\omega + \omega_c) \big]$$
- 记低通等效卷积的频域输出为 $Y_L(\omega) = F_L(\omega) H_L(\omega) \longleftrightarrow y_L(t) = f_L(t)*h_L(t)$，则：
  $$Y(\omega) = \frac{1}{2}\big[ Y_L(\omega - \omega_c) + Y_L(\omega + \omega_c) \big]$$
- 对上式取傅里叶逆变换，由调制性质直接得：
  $$y(t) = y_L(t)\cos(\omega_c t)$$
- 原命题获证。

</details>
