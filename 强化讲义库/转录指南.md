## 二、标准工作流程（每个专题一批）

建议按 2~4 个专题为一批推进（单轮会话做完一批并验收、push）。

### 第 1 步：渲染页面

```python
import pymupdf
doc = pymupdf.open('pdf/27强化讲义.pdf')
for p in range(物理起始索引, 物理结束索引):   # 0-based
    pix = doc[p].get_pixmap(dpi=150)
    pix.save(f'_render/lecture27/hp{p+1:03d}.png')
# 答案 PDF：
d2 = pymupdf.open('pdf/强化讲义专题{中文数字}答案.pdf')
for p in range(d2.page_count):
    d2[p].get_pixmap(dpi=100).save(f'_render/ans{中文数字}/a{p+1:03d}.png')
```

### 第 2 步：逐页看图转录题干

- 用 Read 工具逐页看 `_render/lecture27/hp*.png`（150dpi 足够辨认，个别上下标模糊处用 200dpi 重渲染单页）。
- 区分「专题X 题目」（基础题）与「强化专题X 习题」（强化题）两个题号体系，转录时**连续编号**：基础题 1..M、强化题续为 M+1..N。
- 扫描件公式务必逐个分式/上下标核对，宁可重看一页。
- 注意跳过空白页（很多题目页之间夹空白页）。

### 第 3 步：建立题→手写答案页映射

- 逐页看 `_render/ans{中文数字}/a*.png`，记录每页开头解答的题号。
- **坑**：答案页顺序可能与题目顺序不完全一致（专题二答案 a9–a12 有错位）；专题八的强 1、强 2 解答疑似漏扫缺失。映射必须逐页确认，缺失的题在卡内链接指向相邻页并在解析中说明。

### 第 4 步：撰写解析（质量核心）

- 每题自己完整推导一遍（KaTeX 语法），**每个分式系数、每个符号都要代数自检**——手写答案本身有错（见第五节清单），不能盲抄。
- 与手写答案交叉核对：结论一致则放心；不一致时先怀疑自己，重推确认自己正确后在卡内解析末尾加 `> 注：手写答案……` 说明差异。
- 风格参照 `强化讲义库/讲义专题05_*.md`：分小问、关键步骤、结论加粗或 boxed；简单题 3~5 行，大题可长。
- 选择题给出答案字母 + 逐项判断理由。

### 第 5 步：裁题干图

- 只有「题干信息必须靠图」的题才裁图（波形图/框图/频谱图）。纯文字题不需要。
- 命名：`images/lg/fig-t{专题两位号}-q{连续题号}.png`（如 `fig-t09-q3.png`）。一个题多幅图可裁成一张（并排整体裁）或分多张（meta 的原图行写多行）。
- 方法：先渲染 100dpi 页面叠 10% 比例网格（红色竖线+蓝色横线+百分比标注），Read 目测图的包围盒百分比坐标，再按比例坐标从 200dpi 渲染图上裁剪 + 白边 trim + Read 目检。需要 trim 函数和网格叠加的现成代码见 `_render/crop.py` 或本文档附录。
- 常见问题：裁进上一行/下一行文字残字 → 收紧窗口（残字与图间隙可能只有 1~2 个千分比，多试几次）；trim 的 pad 会把残字带回来，必要时用固定窗口不 trim。

### 第 6 步：写 Markdown 文件

文件：`强化讲义库/讲义专题{NN}_{主题}.md`（NN 两位数）。**严格按以下格式**（构建器 `parseLectFile` 依赖它）：

```markdown
# 27 强化讲义 · 专题九 抽样定理（风中醉风）

> 题目摘自《27强化讲义》专题九（"专题九 题目"X 题 + "强化专题九 习题"Y 题，连续编号 1-Z）。
> 解析为自撰文字版；原书手写解答经卡片底部「手写答案 PDF」链接查看对应页。

#### 讲义 9-1 ｜ 短标题
> **归类** 3.3 抽样定理与无失真恢复系统
> **原图** `images/lg/fig-t09-q3.png`
> **出处** 27强化讲义 专题九题目 第3题
> **页码** 126
> **答案页** 2

**题干**

（题目原文，KaTeX 行内 $...$ / 独立 $$...$$。图一律不放题干里！）

<details><summary>📖 解答</summary>

（自撰解析。）

[答案原文件 · 专题九 p2](../pdf/强化讲义专题九答案.pdf#page=2)

</details>

---

#### 讲义 9-2 ｜ ...
```

**格式红线**：

- meta 顺序随意但键名必须精确（构建器 META_KEYS：细分/题源/原图/出处/页码/归类/答案页/专题）。
- `原图` 的值用反引号包路径（`` `images/lg/...` ``），构建器自动加 `../` 前缀；同键多行 = 多张图。
- `页码` = 讲义 PDF **物理页**；`答案页` = 手写答案 PDF 页（跨页写如 `2-3`，取第一页即可）。
- **题干里绝对不要写 `![...](...)` markdown 图片行**——会与原图 meta 渲染重复（双图 bug，历史上已清理过一次）。
- 解析 details 末尾的答案链接格式：`[答案原文件 · 专题九 p2](../pdf/强化讲义专题九答案.pdf#page=2)`。
- 卡间用 `---` 分隔；构建器解析的题干终止于 `<details>`、`---` 或下一个标题。

## 四、已知坑清单（血泪教训，务必读）

1. **双图 bug**：题干里写 markdown 图片行会和 `原图` meta 的题图区重复渲染各一张。图只走 meta，题干里用文字描述（"波形如图所示（…文字描述…）"）。
2. **答案 PDF 页序错乱/缺页**：专题二答案 a9–a12 顺序错位；**专题八强 1、强 2 的解答在 25 页中未找到**（这两卡解析自撰、答案链接指向相邻页）。每题映射逐页确认。
3. **手写答案有错**，已发现并在卡内加注的：专题一强 3(1) 帕塞瓦尔左端误写 ∫f dt（正确 E=2π/3）；专题四 4-9 手写多写系数 2；专题四强 1 手写波形 (0,1) 段与推导不符；专题五 5-8 手写疑似漏 sgn 跳变因子 2（正确 y=2(e^{−t}−e^{−2t})u(t)）；专题七 7-3(5) 手写按 φ=−3ω 但图是过 (−1,2) 的直线（斜率 −2）。遇到与手写不一致：先重推自己两遍，确认后以推导为准并加注。
4. **KaTeX 打字错误会让构建报错**：`\j` 不是合法命令、`$` 里残留中文问号/残字等。构建报告会列出，必须清零。
5. **裁图残字**：题目行与图距离很近时，trim 的 pad 会把残字带回。用固定窗口多试几次 y0/y1（比例坐标精度 0.5% 级）。
6. **图懒加载假阴性**：浏览器检查 `.thumb` 的 complete 会因 loading=lazy 误报未加载，用 fetch HEAD 复核。
7. **本地服务器**：`python -m http.server 8642 --bind 127.0.0.1` 后台常驻；偶尔会挂，重启即可。用户浏览器开着 http://127.0.0.1:8642/app/index.html。
8. **Bash 工具偶发乱码/伪造输出**：关键结论用 node / grep / Read 交叉验证。
9. **deploy/ 目录**：`deploy/app/` 是独立打包副本，没有同步脚本，与 app/ 不同步——不用管它（用户知情）。

from PIL import ImageChops
import io
def trim(im, tol=10):
    bgim = Image.new('RGB', im.size, (255,255,255))
    diff = ImageChops.difference(im.convert('RGB'), bgim).point(lambda p: 255 if p > tol else 0)
    bbox = diff.getbbox()
    if bbox:
        pad = 6
        return im.crop((max(0,bbox[0]-pad), max(0,bbox[1]-pad), min(im.width,bbox[2]+pad), min(im.height,bbox[3]+pad)))
    return im
