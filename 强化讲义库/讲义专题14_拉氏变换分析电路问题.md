#### 讲义 14-1 ｜ RLC并联支路串联电路的S域模型与零状态响应
> **归类** 4.1 动态电路 S 域模型与全响应
> **原图** `images/lg/fig-t14-q1.png`
> **出处** 27强化讲义 专题十四题目 第1题
> **页码** 189
> **答案页** 1

**题干**

已知电路的输入信号为 $u_i(t)$，输出信号为 $u_o(t)$。$u_i(t)$ 如图所示，电路图如下所示，$R=5\,\Omega$，$C=0.1\,\text{F}$，$L=2\,\text{H}$。

(1) 画出 $s$ 域电路模型；  
(2) 求 $H(s)$；  
(3) 求系统的零状态响应。

<details><summary>📖 解答</summary>

**(1) $s$ 域电路模型：**

在零状态条件下，各元件的 $s$ 域阻抗分别为：
- 电感 $L=2\,\text{H}$：阻抗为 $sL = 2s$；
- 电阻 $R=5\,\Omega$：阻抗为 $5$；
- 电容 $C=0.1\,\text{F}$：阻抗为 $\dfrac{1}{sC} = \dfrac{10}{s}$。

输入端电压像函数为 $U_i(s)$，输出端电压像函数为 $U_o(s)$（取自电阻与电容并联支路两端）。

**(2) 系统函数 $H(s)$：**

并联支路的等效阻抗为：
$$Z_p(s) = R \parallel \frac{1}{sC} = \frac{5 \cdot \frac{10}{s}}{5 + \frac{10}{s}} = \frac{50}{5s + 10} = \frac{10}{s + 2}$$

由分压公式，电压转移函数为：
$$H(s) = \frac{U_o(s)}{U_i(s)} = \frac{Z_p(s)}{2s + Z_p(s)} = \frac{\frac{10}{s+2}}{2s + \frac{10}{s+2}} = \frac{10}{2s(s+2) + 10} = \frac{5}{s^2 + 2s + 5}$$

$$\boxed{\ H(s) = \frac{5}{s^2 + 2s + 5}\ }$$

**(3) 零状态响应 $y_{zs}(t)$：**

由波形图，输入信号为宽度为 $1$ 的矩形脉冲：
$$u_i(t) = u(t) - u(t-1) \implies U_i(s) = \frac{1 - \mathrm{e}^{-s}}{s}$$

零状态响应像函数：
$$Y_{zs}(s) = U_i(s) H(s) = \frac{5}{s(s^2 + 2s + 5)}\left(1 - \mathrm{e}^{-s}\right)$$

令阶跃响应辅助函数 $F(s) = \dfrac{5}{s(s^2 + 2s + 5)}$，展开为部分分式：
$$F(s) = \frac{A}{s} + \frac{Bs + D}{s^2 + 2s + 5}$$

求得：
- $A = \left.\dfrac{5}{s^2 + 2s + 5}\right|_{s=0} = 1$；
- 通分对照分子：$5 = (s^2 + 2s + 5) + s(Bs + D) \implies B = -1,\ D = -2$。

因此：
$$F(s) = \frac{1}{s} - \frac{s + 2}{(s+1)^2 + 2^2} = \frac{1}{s} - \frac{s + 1}{(s+1)^2 + 2^2} - \frac{1}{2}\cdot\frac{2}{(s+1)^2 + 2^2}$$

取拉氏逆变换：
$$f(t) = \left[1 - \mathrm{e}^{-t}\cos(2t) - \frac{1}{2}\mathrm{e}^{-t}\sin(2t)\right]u(t)$$

由时移性质，$y_{zs}(t) = f(t) - f(t-1)u(t-1)$：
$$\boxed{\ y_{zs}(t) = \left[1 - \mathrm{e}^{-t}\cos(2t) - \frac{1}{2}\mathrm{e}^{-t}\sin(2t)\right]u(t) - \left[1 - \mathrm{e}^{-(t-1)}\cos 2(t-1) - \frac{1}{2}\mathrm{e}^{-(t-1)}\sin 2(t-1)\right]u(t-1)\ }$$

#### 讲义 14-2 ｜ 并联支路电路的无失真传输条件
> **归类** 4.1 动态电路 S 域模型与全响应
> **原图** `images/lg/fig-t14-q2.png`
> **出处** 27强化讲义 专题十四题目 第2题
> **页码** 189
> **答案页** 1

**题干**

在下图所示电路中，已知 $L=1\,\text{H}$，$C=1\,\text{F}$，$i(t)$ 为系统的输入，$u_2(t)$ 为系统输出。若要实现无失真传输，$R_1$ 和 $R_2$ 的值为多少？

A. $0.5$、$1$ \quad B. $2$、$0.5$ \quad C. $1$、$1$ \quad D. $2$、$1$

<details><summary>📖 解答</summary>

电流源激励并联两支路：
- 支路 1：电容 $C$ 串联电阻 $R_1$，阻抗为 $Z_1(s) = R_1 + \dfrac{1}{sC} = R_1 + \dfrac{1}{s}$；
- 支路 2：电阻 $R_2$ 串联电感 $L$，阻抗为 $Z_2(s) = R_2 + sL = R_2 + s$。

输出端电压 $U_2(s)$ 为两支路并联总端电压：
$$U_2(s) = I(s)\cdot (Z_1(s) \parallel Z_2(s))$$

转移阻抗系统函数为：
$$H(s) = \frac{U_2(s)}{I(s)} = \frac{Z_1(s)Z_2(s)}{Z_1(s) + Z_2(s)} = \frac{\left(R_1 + \frac{1}{s}\right)(R_2 + s)}{s + R_1 + R_2 + \frac{1}{s}} = \frac{R_1 s + R_1 R_2 + 1 + \frac{R_2}{s}}{s + (R_1 + R_2) + \frac{1}{s}}$$

要实现无失真传输，系统函数必须为常数（幅频为常数，相频为 0，实现零群时延无失真传输）。

当取 $R_1 = 1\,\Omega$，$R_2 = 1\,\Omega$ 时：
- 分子为：$s + 1\cdot 1 + 1 + \dfrac{1}{s} = s + 2 + \dfrac{1}{s}$；
- 分母为：$s + 2 + \dfrac{1}{s}$。

分子分母完全对消，得到：
$$H(s) = 1 = \text{常数}$$

此时 $u_2(t) = i(t)$，完全满足无失真传输条件。

故选 **C**。

#### 讲义 14-3 ｜ 桥式全通网络的系统函数与响应分解
> **归类** 4.3 零极点配置与全通系统
> **原图** `images/lg/fig-t14-q3.png`
> **出处** 27强化讲义 专题十四题目 第3题
> **页码** 190
> **答案页** 2

**题干**

电路如下图所示。

(1) 写出电压转移函数 $H(s)=\dfrac{V_2(s)}{V_1(s)}$；  
(2) 画出 $H(s)$ 的零极点分布，并判断该系统的频率选择特性；  
(3) 若激励 $v_1(t)=10\sin t\,u(t)$，求响应 $v_2(t)$，并指出自由响应、强迫响应、暂态响应和稳态响应。

<details><summary>📖 解答</summary>

**(1) 电压转移函数 $H(s)$：**

设参考地为输入下端点。电路为对称格形电桥结构：
- 右上输出端点电位由电阻 $1\,\Omega$ 与电容 $1\,\text{F}$（阻抗 $\dfrac{1}{s}$）分压确定：
$$V_{2+}(s) = V_1(s)\cdot \frac{\frac{1}{s}}{1 + \frac{1}{s}} = V_1(s)\frac{1}{s+1}$$
- 右下输出端点电位由电容 $\dfrac{1}{s}$ 与电阻 $1\,\Omega$ 分压确定：
$$V_{2-}(s) = V_1(s)\cdot \frac{1}{1 + \frac{1}{s}} = V_1(s)\frac{s}{s+1}$$

两端点差模输出电压为：
$$V_2(s) = V_{2+}(s) - V_{2-}(s) = V_1(s)\left(\frac{1}{s+1} - \frac{s}{s+1}\right) = V_1(s)\frac{1-s}{s+1}$$

$$\boxed{\ H(s) = \frac{1-s}{s+1} = -\frac{s-1}{s+1}\ }$$

**(2) 零极点分布与频率选择特性：**

- 零点：$s = 1$（位于右半平面）；
- 极点：$s = -1$（位于左半平面）。

零点与极点关于虚轴（$j\omega$ 轴）对称分布。
在虚轴上，幅频特性为：
$$|H(j\omega)| = \left|\frac{1-j\omega}{1+j\omega}\right| = \frac{\sqrt{1+\omega^2}}{\sqrt{1+\omega^2}} = 1$$
全频带增益恒定为 1，故该系统为**全通系统**（全通滤波器）。

**(3) 响应求解与成分分解：**

激励 $v_1(t) = 10\sin t\,u(t)$ 的拉氏变换为：
$$V_1(s) = \frac{10}{s^2 + 1}$$

响应像函数：
$$V_2(s) = V_1(s) H(s) = \frac{10(1-s)}{(s+1)(s^2+1)}$$

部分分式展开：
$$V_2(s) = \frac{A}{s+1} + \frac{Bs + C}{s^2+1}$$
- $A = \left.\dfrac{10(1-s)}{s^2+1}\right|_{s=-1} = \dfrac{20}{2} = 10$；
- 比较分子系数求得 $B = -10,\ C = 0$。

故：
$$V_2(s) = \frac{10}{s+1} - \frac{10s}{s^2+1}$$

取拉氏逆变换得时域全响应：
$$\boxed{\ v_2(t) = \left[10\mathrm{e}^{-t} - 10\cos t\right]u(t)\,\text{V}\ }$$

各成分分类如下：
- **自由响应**（对应系统固有模态极点 $s=-1$）：$10\mathrm{e}^{-t}u(t)\,\text{V}$；
- **强迫响应**（对应外加激励极点 $s=\pm j$）：$-10\cos t\,u(t)\,\text{V}$；
- **暂态响应**（随 $t\to\infty$ 衰减至 0 的项）：$10\mathrm{e}^{-t}u(t)\,\text{V}$；
- **稳态响应**（随 $t\to\infty$ 持续存在的正弦稳态项）：$-10\cos t\,u(t)\,\text{V}$。

#### 讲义 14-4 ｜ 双电感梯形电路的阶跃全响应
> **归类** 4.1 动态电路 S 域模型与全响应
> **原图** `images/lg/fig-t14-q4.png`
> **出处** 27强化讲义 专题十四题目 第4题
> **页码** 191
> **答案页** 3

**题干**

对于如下图(b)所示输入 $x(t)$，求图(a)电路 $t \ge 0$ 时的电流 $y_1(t)$ 和 $y_2(t)$。

<details><summary>📖 解答</summary>

**1. 求 $0_-$ 时刻初始状态：**

$t < 0$ 时输入为直流 $x(t) = 3\,\text{V}$，电路处于直流稳态。两电感均视为短路。
电路总等效电阻为：
$$R_{eq} = 1 + (1 \parallel 1) = 1.5\,\Omega$$
电感电流初值为：
$$y_1(0_-) = \frac{3\,\text{V}}{1.5\,\Omega} = 2\,\text{A},\qquad y_2(0_-) = \frac{1}{2}y_1(0_-) = 1\,\text{A}$$
由换路定则：$y_1(0_+) = 2\,\text{A}$，$y_2(0_+) = 1\,\text{A}$。

**2. 建立 $t > 0$ 的 $s$ 域模型：**

$t > 0$ 时输入阶跃跳变为 $x(t) = 6\,\text{V} \implies X(s) = \dfrac{6}{s}$。
- 电感 $L_1 = 1\,\text{H}$ 附带初始电流 $y_1(0_-) = 2\,\text{A}$，串联等效为阻抗 $s$ 与附加电压源 $L_1 y_1(0_-) = 2\,\text{V}$（方向向右，左负右正）；
- 电感 $L_2 = 1\,\text{H}$ 附带初始电流 $y_2(0_-) = 1\,\text{A}$，串联等效为阻抗 $s$ 与附加电压源 $L_2 y_2(0_-) = 1\,\text{V}$（方向向右，左负右正）。

**3. 节点电压法求解：**

设两电感之间的中间节点电压为 $U_{n1}(s)$，参考地为电路底端导线：
- 左支路电流（流入节点）：$\dfrac{\frac{6}{s} + 2 - U_{n1}(s)}{s + 1}$；
- 中支路电阻 $1\,\Omega$ 流出电流：$U_{n1}(s)$；
- 右支路流出电流：$\dfrac{U_{n1}(s) - (-1)}{s + 1} = \dfrac{U_{n1}(s) + 1}{s + 1}$。

列写 KCL 方程：
$$\left(\frac{1}{s+1} + 1 + \frac{1}{s+1}\right) U_{n1}(s) = \frac{\frac{6}{s} + 2}{s+1} - \frac{1}{s+1}$$
$$\frac{s+3}{s+1} U_{n1}(s) = \frac{\frac{6}{s} + 1}{s+1} = \frac{s+6}{s(s+1)} \implies U_{n1}(s) = \frac{s+6}{s(s+3)}$$

**4. 支路电流反变换：**

- $Y_1(s)$：
$$Y_1(s) = \frac{\frac{6}{s} + 2 - U_{n1}(s)}{s+1} = \frac{\left(2 + \frac{6}{s}\right)(s+3) - (s+6)}{s(s+1)(s+3)} = \frac{2s^2 + 11s + 12}{s(s+1)(s+3)}$$
展开为部分分式：
$$Y_1(s) = \frac{4}{s} - \frac{3/2}{s+1} - \frac{1/2}{s+3}$$
逆变换得：
$$\boxed{\ y_1(t) = \left(4 - \frac{3}{2}\mathrm{e}^{-t} - \frac{1}{2}\mathrm{e}^{-3t}\right)u(t)\,\text{A}\ }$$

- $Y_2(s)$：
$$Y_2(s) = \frac{U_{n1}(s) + 1}{s+1} = \frac{(s+6) + s(s+3)}{s(s+1)(s+3)} = \frac{s^2 + 4s + 6}{s(s+1)(s+3)}$$
展开为部分分式：
$$Y_2(s) = \frac{2}{s} - \frac{3/2}{s+1} + \frac{1/2}{s+3}$$
逆变换得：
$$\boxed{\ y_2(t) = \left(2 - \frac{3}{2}\mathrm{e}^{-t} + \frac{1}{2}\mathrm{e}^{-3t}\right)u(t)\,\text{A}\ }$$

#### 讲义 14-5 ｜ 含受控源反馈系统的传递函数与稳定性
> **归类** 4.1 动态电路 S 域模型与全响应
> **原图** `images/lg/fig-t14-q5.png`
> **出处** 27强化讲义 专题十四题目 第5题
> **页码** 192
> **答案页** 4

**题干**

如图所示反馈系统，其中 $k v_2(t)$ 是受控源。

(1) 求电压转移函数 $H(s)=\dfrac{V_o(s)}{V_1(s)}$；  
(2) $k$ 满足什么条件时系统稳定？

<details><summary>📖 解答</summary>

**(1) 电压转移函数 $H(s)$：**

输出端受控电压源受电压 $v_2(t)$ 控制，故在 $s$ 域中有：
$$V_o(s) = k V_2(s)$$

设前级两电阻中间的节点为节点 1，电位为 $U_{n1}(s)$。
接地电容 $1\,\text{F}$ 上的电压即为控制量 $V_2(s)$。由串联分压：
$$V_2(s) = \frac{\frac{1}{s}}{1 + \frac{1}{s}} U_{n1}(s) = \frac{1}{s+1} U_{n1}(s) \implies U_{n1}(s) = (s+1) V_2(s)$$

在节点 1 处，跨接反馈电容 $1\,\text{F}$（导纳为 $s$）连接到输出端 $V_o(s) = k V_2(s)$。列写节点 1 的 KCL 方程：
$$(1 + s) U_{n1}(s) + \frac{U_{n1}(s) - V_2(s)}{1} = V_1(s) + s V_o(s)$$
$$(s + 2) U_{n1}(s) - V_2(s) = V_1(s) + s k V_2(s)$$

将 $U_{n1}(s) = (s+1) V_2(s)$ 代入：
$$\left[(s+2)(s+1) - 1\right] V_2(s) - s k V_2(s) = V_1(s)$$
$$\left[s^2 + 3s + 1 - s k\right] V_2(s) = V_1(s) \implies V_2(s) = \frac{1}{s^2 + (3-k)s + 1} V_1(s)$$

输出 $V_o(s) = k V_2(s)$，故系统函数为：
$$\boxed{\ H(s) = \frac{V_o(s)}{V_1(s)} = \frac{k}{s^2 + (3-k)s + 1}\ }$$

**(2) 系统稳定性条件：**

系统的特征方程为：
$$D(s) = s^2 + (3-k)s + 1 = 0$$

对于二阶多项式，系统因果稳定的充要条件是特征多项式所有系数同号且严格大于零：
$$a_2 = 1 > 0,\quad a_1 = 3 - k > 0,\quad a_0 = 1 > 0$$

解得：
$$\boxed{\ k < 3\ }$$

#### 讲义 14-6 ｜ 互感耦合电路的去耦等效与冲激/阶跃响应
> **归类** 4.1 动态电路 S 域模型与全响应
> **原图** `images/lg/fig-t14-q6.png`
> **出处** 27强化讲义 专题十四题目 第6题
> **页码** 193
> **答案页** 5

**题干**

互感耦合电路如图所示，若以 $v_s(t)$ 为激励，$v(t)$ 为响应，试求下列情况下的单位冲激响应 $h(t)$ 和单位阶跃响应 $g(t)$。

(1) $R=0.5\,\Omega$；  
(2) $R=1\,\Omega$。

<details><summary>📖 解答</summary>

**1. 互感去耦等效：**

原边电感 $L_1 = 0.5\,\text{H}$，副边电感 $L_2 = 2\,\text{H}$，互感 $M = 0.5\,\text{H}$。
同名端位于两电感上端，公共底端为非同名端。作 T 型去耦等效：
- 原边串联支路电感：$L_1 - M = 0.5 - 0.5 = 0\,\text{H}$；
- 副边串联支路电感：$L_2 - M = 2 - 0.5 = 1.5\,\text{H}$；
- 公共并联支路电感：$M = 0.5\,\text{H}$。

由于副边输出端口开路，流经 $1.5\,\text{H}$ 电感的电流为零，因此输出电压 $v(t)$ 严格等于公共并联支路的端电压。

**2. 系统函数 $H(s)$：**

中间并联支路由电容 $0.5\,\text{F}$（阻抗 $\dfrac{2}{s}$）与电感 $0.5\,\text{H}$（阻抗 $\dfrac{s}{2}$）并联构成：
$$Z_p(s) = \frac{2}{s} \parallel \frac{s}{2} = \frac{1}{\frac{s}{2} + \frac{2}{s}} = \frac{2s}{s^2 + 4}$$

由分压公式：
$$H(s) = \frac{V(s)}{V_s(s)} = \frac{Z_p(s)}{R + Z_p(s)} = \frac{\frac{2s}{s^2+4}}{R + \frac{2s}{s^2+4}} = \frac{\frac{2}{R}s}{s^2 + \frac{2}{R}s + 4}$$

**3. 情况 (1)：$R = 0.5\,\Omega$**

此时 $\dfrac{2}{R} = 4$：
$$H(s) = \frac{4s}{s^2 + 4s + 4} = \frac{4s}{(s+2)^2} = \frac{4}{s+2} - \frac{8}{(s+2)^2}$$

取拉氏逆变换得单位冲激响应：
$$\boxed{\ h(t) = \left(4\mathrm{e}^{-2t} - 8t\mathrm{e}^{-2t}\right)u(t)\ }$$

单位阶跃响应的像函数：
$$G(s) = \frac{H(s)}{s} = \frac{4}{(s+2)^2}$$
取逆变换得：
$$\boxed{\ g(t) = 4t\mathrm{e}^{-2t}u(t)\ }$$

**4. 情况 (2)：$R = 1\,\Omega$**

此时 $\dfrac{2}{R} = 2$：
$$H(s) = \frac{2s}{s^2 + 2s + 4} = \frac{2(s+1) - 2}{(s+1)^2 + 3}$$

取拉氏逆变换得单位冲激响应：
$$\boxed{\ h(t) = \left[2\mathrm{e}^{-t}\cos(\sqrt{3}t) - \frac{2}{\sqrt{3}}\mathrm{e}^{-t}\sin(\sqrt{3}t)\right]u(t)\ }$$

单位阶跃响应的像函数：
$$G(s) = \frac{H(s)}{s} = \frac{2}{(s+1)^2 + 3} = \frac{2}{\sqrt{3}}\cdot\frac{\sqrt{3}}{(s+1)^2 + (\sqrt{3})^2}$$
取逆变换得：

#### 讲义 14-7 ｜ 压控电压源高通滤波器的系统函数与稳定性
> **归类** 4.2 运算放大器与高阶电路系统函数
> **原图** `images/lg/fig-t14-q7.png`
> **出处** 27强化讲义 专题十四题目 第7题
> **页码** 194
> **答案页** 6

**题干**

如图所示电路中含有理想运算放大器，理想运算放大器输入阻抗为无限大，输出阻抗等于零。试求：

(1) 系统函数 $H(s)=\dfrac{V_2(s)}{V_1(s)}$；  
(2) 为保证稳定工作，求放大器放大系数 A 的变化范围；  
(3) 在临界稳定时，求冲激响应 $h(t)$；  
(4) 当 $A=1$，$R_1=R_2=R$，$C_1=C_2=C$ 时，粗略画出系统幅频特性曲线。

<details><summary>📖 解答</summary>

**(1) 系统函数 $H(s)$：**

设内部放大器同相端电位为 $V_A(s)$，输出端电位为 $V_2(s) = A V_A(s)$。
两电容交汇节点记为 $B$，电位为 $V_B(s)$。
- 节点 $A$（无电流流入运放）：
$$V_A(s) = \frac{R_1}{R_1 + \frac{1}{sC_2}} V_B(s) = \frac{sC_2 R_1}{sC_2 R_1 + 1} V_B(s)$$
由 $V_2(s) = A V_A(s)$，有 $V_B(s) = \dfrac{sC_2 R_1 + 1}{A sC_2 R_1} V_2(s)$。
- 节点 $B$ 的 KCL 方程：
$$(sC_1 + sC_2 + \frac{1}{R_2}) V_B(s) = sC_1 V_1(s) + sC_2 V_A(s) + \frac{1}{R_2} V_2(s)$$

将 $V_A(s) = \dfrac{V_2(s)}{A}$ 和 $V_B(s)$ 的表达式代入整理消元，得：
$$\boxed{\ H(s) = \frac{V_2(s)}{V_1(s)} = \frac{A s^2}{s^2 + \left(\frac{C_1+C_2}{C_1 C_2 R_1} + \frac{1-A}{C_1 R_2}\right)s + \frac{1}{C_1 C_2 R_1 R_2}}\ }$$

**(2) 放大系数 $A$ 的变化范围：**

分母多项式为二阶标准形式 $s^2 + a_1 s + a_0$。常数项 $a_0 = \dfrac{1}{C_1 C_2 R_1 R_2} > 0$ 恒成立。
系统因果稳定的充要条件为一次项系数 $a_1 > 0$：
$$\frac{C_1+C_2}{C_1 C_2 R_1} + \frac{1-A}{C_1 R_2} > 0 \iff 1 - A > -\frac{(C_1+C_2)R_2}{C_2 R_1}$$

$$\boxed{\ A < 1 + \frac{R_2}{R_1} + \frac{R_2 C_1}{R_1 C_2}\ }$$

**(3) 临界稳定时的冲激响应 $h(t)$：**

临界稳定时 $a_1 = 0$，即 $A = 1 + \dfrac{R_2}{R_1} + \dfrac{R_2 C_1}{R_1 C_2}$。
令 $\omega_0 = \dfrac{1}{\sqrt{C_1 C_2 R_1 R_2}}$，系统函数化为：
$$H(s) = A \frac{s^2}{s^2 + \omega_0^2} = A\left(1 - \frac{\omega_0^2}{s^2 + \omega_0^2}\right)$$

取拉氏逆变换得单位冲激响应：
$$\boxed{\ h(t) = A\left[\delta(t) - \omega_0\sin(\omega_0 t)u(t)\right]\ }$$
其中 $\omega_0 = \dfrac{1}{\sqrt{C_1 C_2 R_1 R_2}}$。

**(4) 特殊参数下的幅频特性：**

当 $A=1$，$R_1=R_2=R$，$C_1=C_2=C$ 时：
$$H(s) = \frac{s^2}{s^2 + \frac{2}{RC}s + \frac{1}{(RC)^2}} = \frac{s^2}{\left(s + \frac{1}{RC}\right)^2}$$

在原点 $s=0$ 处有二阶零点，在 $s=-\dfrac{1}{RC}$ 处有二阶重极点。
幅频响应表达式：
$$|H(j\omega)| = \frac{\omega^2}{\omega^2 + \frac{1}{(RC)^2}}$$
- $\omega = 0$ 时，$|H(j0)| = 0$；
- $\omega \to \infty$ 时，$|H(j\infty)| = 1$。
系统呈现典型的二阶**高通滤波**特性，幅频曲线在低频处为 0，随频率单调升高并渐近趋向于 1。

#### 讲义 14-8 ｜ 桥式全通电路的系统函数与指数输入零状态响应
> **归类** 4.3 零极点配置与全通系统
> **原图** `images/lg/fig-t14-q8.png`
> **出处** 27强化讲义 专题十四题目 第8题
> **页码** 196
> **答案页** 8

**题干**

线性时不变因果系统如下图所示。

(1) 该系统是否为全通系统？请说明理由；  
(2) 若系统的输入信号 $f(t)=\mathrm{e}^{0.5t}u(t)$，求系统的零状态响应。

<details><summary>📖 解答</summary>

**(1) 全通特性判定：**

将中间 $2\,\Omega$ 负载断开，求开路电压 $U_{oc}(s)$：
- 左桥臂中点电压：$U_a(s) = F(s)\dfrac{1/s}{4s + 1/s} = F(s)\dfrac{1}{4s^2+1}$；
- 右桥臂中点电压：$U_b(s) = F(s)\dfrac{4s}{4s + 1/s} = F(s)\dfrac{4s^2}{4s^2+1}$。

开路差模电压为：
$$U_{oc}(s) = U_a(s) - U_b(s) = F(s)\frac{1 - 4s^2}{4s^2 + 1}$$

独立电压源短路，求得戴维宁等效输出阻抗：
$$Z_{eq}(s) = 2\cdot \left(4s \parallel \frac{1}{s}\right) = \frac{8s}{4s^2 + 1}$$

接入负载电阻 $2\,\Omega$，输出响应为：
$$Y(s) = U_{oc}(s)\frac{2}{2 + Z_{eq}(s)} = F(s)\frac{1-4s^2}{4s^2+1}\cdot\frac{2}{2 + \frac{8s}{4s^2+1}} = F(s)\frac{1-4s^2}{4s^2 + 4s + 1} = F(s)\frac{(1-2s)(1+2s)}{(2s+1)^2}$$

因此系统函数为：
$$\boxed{\ H(s) = \frac{Y(s)}{F(s)} = \frac{1-2s}{2s+1} = \frac{\frac{1}{2}-s}{s + \frac{1}{2}} = -\frac{s - 0.5}{s + 0.5}\ }$$

- 极点：$s = -0.5$（位于左半开平面）；
- 零点：$s = 0.5$（位于右半开平面）。
零极点关于虚轴完全对称分布，且 $|H(j\omega)| = \left|\dfrac{0.5-j\omega}{0.5+j\omega}\right| = 1$ 对所有频率成立，因此该系统**是全通系统**。

**(2) 零状态响应 $y_{zs}(t)$：**

输入信号 $f(t) = \mathrm{e}^{0.5t}u(t)$ 的拉氏变换为 $F(s) = \dfrac{1}{s - 0.5}$。
零状态响应像函数：
$$Y_{zs}(s) = F(s) H(s) = \frac{1}{s - 0.5}\cdot\left(-\frac{s - 0.5}{s + 0.5}\right) = -\frac{1}{s + 0.5}$$

系统在 $s=0.5$ 处的零点完全对消了输入信号在 $s=0.5$ 处的发散极点。
取拉氏逆变换得：
$$\boxed{\ y_{zs}(t) = -\mathrm{e}^{-0.5t}u(t)\ }$$

#### 讲义 14-10 ｜ 理想变压器全通网络的系统函数与零极点

**题干**

如图所示电路，虚框中是 $1:1:1$ 的理想变压器，激励信号为 $v_1(t)$，响应取 $v_2(t)$，写出电压转移函数 $H(s)=\dfrac{V_2(s)}{V_1(s)}$，画出零、极点分布图。指出是否为全通网络。

<details><summary>📖 解答</summary>

**1. 电压转移函数推导：**

变压器变比为 $1:1:1$，同名端均位于各绕组顶端。
原边加激励 $V_1(s)$，副边两绕组串联同向，每个副边绕组两端感应电压均为 $V_1(s)$（上正下负）。
副边外回路由两绕组总感应电动势 $2V_1(s)$ 激励，连接电容 $C$（阻抗 $\dfrac{1}{sC}$）与电阻 $R$ 串联。
电阻 $R$ 两端的电压降为：
$$V_R(s) = 2V_1(s)\frac{R}{R + \frac{1}{sC}}$$

对副边下半回路列写 KVL：
$$V_1(s) + V_2(s) = V_R(s) \implies V_2(s) = V_R(s) - V_1(s)$$

$$V_2(s) = V_1(s)\left(\frac{2R}{R + \frac{1}{sC}} - 1\right) = V_1(s)\frac{R - \frac{1}{sC}}{R + \frac{1}{sC}} = V_1(s)\frac{s - \frac{1}{RC}}{s + \frac{1}{RC}}$$

$$\boxed{\ H(s) = \frac{V_2(s)}{V_1(s)} = \frac{s - \frac{1}{RC}}{s + \frac{1}{RC}}\ }$$

- 零点：$s = \dfrac{1}{RC}$（位于右半开平面实轴上）；
- 极点：$s = -\dfrac{1}{RC}$（位于左半开平面实轴上）。

零点与极点关于虚轴对称，系统的幅频响应：
$$|H(j\omega)| = \left|\frac{j\omega - \frac{1}{RC}}{j\omega + \frac{1}{RC}}\right| = 1\quad (\forall \omega)$$

全频带增益恒等于 1，故该网络**是全通网络**。

#### 讲义 14-12 ｜ 含非零初始状态电路的S域求解与信号流图

**题干**

如图所示电路，原处于稳定状态，在 $t=0$ 时开关 $K$ 闭合，试求：

(1) 电容上的初始电压和电感中的初始电流；  
(2) 画出 $t>0$ 时的 $s$ 域运算等效电路；  
(3) 流过开关 $K$ 的电流 $i(t)$；  
(4) 电路开关 $K$ 保持断开，以电压源电压作为输入，以电感两端电压 $u_L(t)$ 为输出，在零状态条件下选定各结点变量并作出信号流图；

电容电压取自两并联支路对地电位差（上正下负）：
$$u_C(0_-) = 3\,\text{V} \times \frac{2}{3} = 2\,\text{V}$$

**(2) $t>0$ 时的 $s$ 域运算等效电路：**

开关 $K$ 闭合后将其连接点直接短路至地。
- 电容 $C=1\,\text{F}$（阻抗 $\dfrac{1}{s}$），附加初始电压源 $\dfrac{u_C(0_-)}{s} = \dfrac{2}{s}$（上正下负）；
- 电感 $L=2\,\text{H}$（阻抗 $2s$），附加初始电压源 $L i_L(0_-) = 2\,\text{V}$（方向向下，上负下正）；
- 闭合的开关支路从电感与电阻连接节点接至参考地。

**(3) 求解开关电流 $i(t)$：**

设电容上方节点为节点 1，电位为 $U_{n1}(s)$。开关将右侧节点直接接地（电位为 $0$）。
节点 1 的 KCL 方程：
$$(1 + s + 1) U_{n1}(s) = \frac{3/s}{1} + s\cdot\frac{2}{s} = \frac{2s + 3}{s}$$
$$U_{n1}(s) = \frac{2s+3}{s(s+2)}$$

流经中间 $1\,\Omega$ 电阻汇入开关结点的电流：
$$I_1(s) = \frac{U_{n1}(s) - 0}{1} = \frac{2s+3}{s(s+2)}$$
从地经电感支路流回该短路节点的电流（由初始电压源 $2\,\text{V}$ 驱动）：
$$I_2(s) = \frac{0 - (-2)}{2s} \dots \implies \frac{2}{2s} = \frac{1}{s + 0.5}\dots$$
严格计算电感支路阻抗 $2s$ 与附加源 $2$：
$$I_2(s) = \frac{2}{2s+1} = \frac{1}{s + 0.5}$$
开关流出总电流：
$$I(s) = I_1(s) - I_2(s) = \frac{2s+3}{s(s+2)} - \frac{1}{s+0.5} = \frac{3/2}{s} + \frac{1/2}{s+2} - \frac{1}{s+0.5}$$

取逆变换：
$$\boxed{\ i(t) = \left(\frac{3}{2} + \frac{1}{2}\mathrm{e}^{-2t} - \mathrm{e}^{-0.5t}\right)u(t)\,\text{A}\ }$$

开关断开且零状态时，设三个独立节点电压为 $U_1(s)$（电容上端）、$U_2(s)$（中间电阻右端）、$U_3(s) = U_L(s)$（电感上端）。
列写节点电压方程并整理因果关系：
$$U_1(s) = \frac{1}{s+2} U_s(s) + \frac{1}{s+2} U_2(s)$$
$$U_2(s) = \frac{1}{2} U_1(s) + \frac{1}{2} U_3(s)$$

#### 讲义 14-13 ｜ 倒相放大器电路的信号流图、梅森公式与系统稳定性
> **归类** 4.2 运算放大器与高阶电路系统函数
> **原图** `images/lg/fig-t14-q13.png`
> **出处** 27强化讲义 专题十四题目 第13题
> **页码** 202
> **答案页** 14

**题干**

已知一个运算放大器，如图所示，若倒相放大器是理想放大器，其输入阻抗为无限大，输出阻抗为零。

(1) 画出信号流图；  
(2) 用梅森公式求出 $H(s)=\dfrac{V_o(s)}{V_i(s)}$，求 $K$ 为何值时，系统处于稳定或者临界稳定？  
(3) 写出原电路的系统方程。

<details><summary>📖 解答</summary>

**(1) 信号流图绘制：**

设倒相放大器输入端电压为 $V_1(s)$，输出端电压为 $V_o(s) = -K V_1(s)$。
反馈网络总阻抗为 $Z(s)$：
$$Z(s) = (R_1 \parallel \frac{1}{sC_1}) + \frac{1}{sC_2} = \frac{R_1}{1 + sC_1 R_1} + \frac{1}{sC_2} = \frac{1 + s(C_1+C_2)R_1}{sC_2(1 + sC_1 R_1)}$$

因放大器输入阻抗无穷大，输入端节点 $V_1(s)$ 满足：
$$\frac{V_i(s) - V_1(s)}{R_0} + \frac{V_o(s) - V_1(s)}{Z(s)} = 0 \implies V_1(s) = \frac{Z(s)}{R_0 + Z(s)} V_i(s) + \frac{R_0}{R_0 + Z(s)} V_o(s)$$

由此画出信号流图：
- 前向支路：$V_i(s) \xrightarrow{\frac{Z(s)}{R_0 + Z(s)}} V_1(s) \xrightarrow{-K} V_o(s)$；
- 反馈支路：$V_o(s) \xrightarrow{\frac{R_0}{R_0 + Z(s)}} V_1(s)$。

**(2) 梅森公式求 $H(s)$ 与系统稳定性：**

前向通路增益：$P_1 = \dfrac{-K Z(s)}{R_0 + Z(s)}$，$\Delta_1 = 1$。
单回路增益：$L_1 = \dfrac{-K R_0}{R_0 + Z(s)}$。
特征式：
$$\Delta = 1 - L_1 = \frac{(K+1)R_0 + Z(s)}{R_0 + Z(s)}$$

因此：
$$H(s) = \frac{P_1}{\Delta} = \frac{-K Z(s)}{(K+1)R_0 + Z(s)}$$

代入 $Z(s)$ 整理得：
$$\boxed{\ H(s) = \frac{-K(C_1 R_1 + C_2 R_1)s - K}{(K+1)C_1 C_2 R_0 R_1 s^2 + \left[R_1 C_1 + R_1 C_2 + (K+1)R_0 C_2\right]s + 1}\ }$$

**稳定性分析：**
特征方程为二阶多项式，由劳斯判据，系统稳定的充要条件是各项系数均大于零：
$$\begin{cases} a_2 = (K+1)C_1 C_2 R_0 R_1 > 0 \implies K > -1 \\ a_1 = R_1(C_1 + C_2) + (K+1)R_0 C_2 > 0 \implies K > -1 - \frac{R_1(C_1+C_2)}{R_0 C_2} \end{cases}$$
综合得稳定条件为：
$$\boxed{\ K > -1\ }$$

> 注：当 $K=-1$ 时二次项系数为 0，系统降为一阶，极点为负实数，仍稳定；当 $a_1=0$ 时二次项系数 $a_2 < 0$，系统极点为一正一负实根而非虚轴共轭极点，故**不存在临界稳定状态**。

**(3) 原电路系统微分方程：**

对 $H(s) = \dfrac{Y(s)}{X(s)}$ 交叉相乘并取拉氏逆变换：
$$\boxed{\ (K+1)C_1 C_2 R_0 R_1\,y''(t) + \left[R_1 C_1 + R_1 C_2 + (K+1)R_0 C_2\right]y'(t) + y(t) = -K(C_1 R_1 + C_2 R_1)x'(t) - K x(t)\ }$$

(2) 求零输入响应 $i_x(t)$；  
(3) 已知全响应 $i(t)=\left(-57\mathrm{e}^{-3t}+136\mathrm{e}^{-4t}\right)u(t)$，求零状态响应 $i_f(t)$；

将激励置零（$F(s)=0$ 短路）：

$$I_f(s) = \frac{-30}{s+3} + \frac{80}{s+4} = \frac{10(5s+12)}{s^2 + 7s + 12}$$

由 $F(s) = \dfrac{I_f(s)}{H(s)}$：
$$F(s) = \frac{\frac{10(5s+12)}{s^2+7s+12}}{\frac{s(5s+12)}{s^2+7s+12}} = \frac{10}{s}$$

取拉氏逆变换得：
$$\boxed{\ f(t) = 10u(t)\,\text{V}\ }$$

#### 讲义 14-20 ｜ 运放延时校正放大电路的阶跃响应
> **归类** 4.2 运算放大器与高阶电路系统函数
> **原图** `images/lg/fig-t14-q20.png`
> **出处** 27强化讲义 强化专题十四习题 第7题
> **页码** 209
> **答案页** 23

**题干**

如图所示含有理想运算放大器的系统，$u(t)$ 为单位阶跃信号，求输出 $u_o(t)$。

<details><summary>📖 解答</summary>

电路为同相放大电路构型：
- 输入信号为单位阶跃信号 $u(t) \implies \dfrac{1}{s}$，加在同相端；
- 反相端接电阻 $R_1$ 到地，并通过反馈网络 $(R_2 \parallel \dfrac{1}{sC})$ 连接到输出端 $u_o(t)$。

> 注：原讲义电路图符号中运放输入端标注 $-, +$ 疑似印刷颠倒；按理想运放线性放大区工作条件，反馈网络必须接反相端构成负反馈。

由理想运放「虚短」与「虚断」性质：
$$U_-(s) = U_+(s) = \frac{1}{s}$$

由反相端分压关系：
$$U_-(s) = U_o(s) \frac{R_1}{R_1 + Z_f(s)}$$
其中反馈阻抗为：
$$Z_f(s) = R_2 \parallel \frac{1}{sC} = \frac{R_2}{sCR_2 + 1}$$

因此输出电压像函数为：
$$U_o(s) = U_-(s)\left(1 + \frac{Z_f(s)}{R_1}\right) = \frac{1}{s}\left(1 + \frac{R_2}{R_1(sCR_2 + 1)}\right) = \frac{1}{s} + \frac{R_2/R_1}{s(sCR_2 + 1)}$$

对第二项进行部分分式展开：
$$\frac{R_2/R_1}{s(sCR_2 + 1)} = \frac{1}{CR_1}\frac{1}{s\left(s + \frac{1}{CR_2}\right)} = \frac{R_2}{R_1}\left(\frac{1}{s} - \frac{1}{s + \frac{1}{CR_2}}\right)$$

合并得：
$$U_o(s) = \frac{1 + \frac{R_2}{R_1}}{s} - \frac{\frac{R_2}{R_1}}{s + \frac{1}{CR_2}}$$

取拉氏逆变换得输出响应：
$$\boxed{\ u_o(t) = \left(1 + \frac{R_2}{R_1} - \frac{R_2}{R_1}\mathrm{e}^{-\frac{t}{CR_2}}\right)u(t)\ }$$
