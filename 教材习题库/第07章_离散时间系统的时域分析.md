#### 教材 7-7 ｜ 左边序列的求解与解释
> **归类** 5.1
> **页码** 224

**题干**

在习题 7-5 中，若限定当 $n>0$ 时，全部 $y(n)=0$，以 $y(1)=0$ 为边界条件，当 $x(n) = \delta(n)$ 时的响应 $y(n)$，这时，可以得到一个左边序列，试解释为什么会出现这种结果。

<details><summary>📖 解答</summary>

解：根据题 7-5 可知

$$y(n) = x(n) + \frac{1}{3}y(n-1)$$

当 $n>0$ 时，$y(n)=0$，$y(1)=0$。将差分方程改写为

$$y(n-1) = 3y(n) - 3x(n)$$

迭代求出

$$y(0) = 0,\quad y(-1) = -3,\quad y(-2) = -3^{2},\ \cdots$$

$$y(n) = -3^{-n}$$

所以 $y(n) = -3^{-n} u(-n-1)$ 为一个左边序列。

$y(n)$ 为左边序列是因为限定了 $n>0$ 时的所有 $y(n)=0$，因而 $y(n)$ 的第一个非 0 值只能出现在 $n<0$ 的范围内，否则无法满足边界条件。出现这种情况的原因在于差分方程的结构，即以递推的方式描述了输入序列和输出序列的局部（相对时间内）的约束关系，因而能够根据边界条件按时间顺序或逆序进行递归，所以可能得到右边或左边两种序列。

</details>

#### 教材 7-11 ｜ 一阶齐次差分方程求解
> **归类** 5.1
> **页码** 225

**题干**

解差分方程

(1) $y(n) - \dfrac{1}{2}y(n-1) = 0, y(0) = 1$；

(2) $y(n) - 2y(n-1) = 0, y(0) = \dfrac{1}{2}$；

(3) $y(n) + 3y(n-1) = 0, y(1) = 1$；

(4) $y(n) + \dfrac{2}{3}y(n-1) = 0, y(0) = 1$。

<details><summary>📖 解答</summary>

（2）由特征方程 $\alpha - 2 = 0$，解得特征根 $\alpha = 2$，故可设齐次解为：$y(n) = C \cdot 2^{n}$。

代入初始条件 $y(0) = \dfrac{1}{2}$，解得 $C = \dfrac{1}{2}$，所以 $y(n) = 2^{n-1}$。

（3）由特征方程 $\alpha + 3 = 0$，解得特征根 $\alpha = -3$，故可设齐次解为：$y(n) = C \cdot (-3)^{n}$。

代入初始条件 $y(1)=1$，解得 $C = -\dfrac{1}{3}$，所以 $y(n) = (-3)^{n-1}$。

（4）由特征方程 $\alpha + \dfrac{2}{3} = 0$，解得特征根 $\alpha = -\dfrac{2}{3}$，故可设齐次解为：$y(n) = C \cdot \left(-\dfrac{2}{3}\right)^{n}$。

代入初始条件 $y(0)=1$，解得 $C=1$，所以 $y(n) = \left(-\dfrac{2}{3}\right)^{n}$。

#### 教材 7-18 ｜ 迭代求解与特解形式讨论
> **归类** 5.1
> **页码** 229

**题干**

解差分方程 $y(n)-y(n-1)=n$，已知 $y(-1)=0$
(1)用迭代法逐次求出数值解，归纳一个闭式解答(对于 $n\geqslant 0$)；
(2)分别求齐次解与特解，讨论此题应如何假设特解函数式。

<details><summary>📖 解答</summary>

解：（1）由 $y(n)-y(n-1)=n$ 及 $y(-1)=0$，有

$$y(0)=0=\frac{0\times 1}{2},\quad y(1)=1=\frac{1\times 2}{2},\quad y(2)=\frac{2\times 3}{2},\ \cdots$$

$$y(n)=\frac{n(n+1)}{2}\ (n\geqslant 0)$$

（2）由特征方程 $a-1=0$，解得特征根 $a=1$，所以齐次解为：$C$。

设特解为 $D_1 n+D_2$，代入原差分方程无法确定待定系数。差分方程 $y(n)-y(n-1)=n$ 暗示着 $y(n)$ 中含有 $n^2$ 分量，所以设特解为 $D_1 n^2+D_2 n$，代入原差分方程，有

$$2D_1 n-(D_1-D_2)=n$$

解得：$D_1=D_2=\frac{1}{2}$，故全解为：$y(n)=C+\frac{1}{2}n^2+\frac{1}{2}n$。

代入初始条件 $y(-1)=0$，解得：$C=0$

所以 $y(n)=\frac{n(n+1)}{2}\ (n\geqslant 0)$。

</details>

#### 教材 7-33 ｜ 级联系统卷积结合律验证
> **归类** 5.2
> **页码** 240

**题干**

如图 7-18 所示的系统包括两个级联的线性时不变系统，它们的单位样值响应分别为 $h_1(n)$ 和 $h_2(n)$，已知 $h_1(n) = \delta(n) - \delta(n-3)$，$h_2(n) = (0.8)^{n}u(n)$ 令 x(n)=u(n)。

（1）按下式求 $y(n)$：$y(n) = \left[x(n) * h_1(n)\right] * h_2(n)$

（2）按下式求 $y(n)$：$y(n) = x(n) * \left[h_1(n) * h_2(n)\right]$

两种方法的结果应当是一样的(卷积结合律)。

<details><summary>📖 解答</summary>

解：（1）

$$
\begin{aligned}
y(n) &= \left[u(n) - u(n-3)\right] * 0.8^{n}u(n) \\
&= \sum_{m=0}^{n} 0.8^{m} - \sum_{m=0}^{n-3} 0.8^{m} \\
&= \frac{1 - (0.8)^{n+1}}{1 - 0.8} \cdot u(n) - \frac{1 - (0.8)^{n-2}}{1 - 0.8} u(n-3)
\end{aligned}
$$

（2）

$$
\begin{aligned}
y(n) &= u(n) * \left[0.8^{n}u(n) - 0.8^{n-3}u(n-3)\right] \\
&= \frac{1 - (0.8)^{n+1}}{1 - 0.8} \cdot u(n) - \frac{1 - (0.8)^{n-2}}{1 - 0.8} u(n-3)
\end{aligned}
$$

可见(1)(2)的计算结果一样，说明卷积满足结合律。

</details>

#### 教材 7-34 ｜ 卷积输出非零区间的确定
> **归类** 5.2
> **页码** 241

**题干**

已知一线性时不变系统的单位样值响应 h(n)，除在 $N_0 \leqslant n \leqslant N_1$ 区间之外都为零。而输入 x(n)除在区间 $N_2 \leqslant n \leqslant N_3$ 之外均为零。这样，响应 y(n)除在 $N_4 \leqslant n \leqslant N_5$ 之外均被限制为零。试用 $N_0, N_1, N_2, N_3$ 来表示 $N_4$ 与 $N_5$。

<details><summary>📖 解答</summary>

解：根据定义有

$$y(n) = h(n) * x(n) = \sum_{m=-\infty}^{\infty} h(m) \cdot x(n-m)$$

因 h(m)的非零区域为 $N_0 \leqslant m \leqslant N_1$，x(n-m)的非零区域为 $N_2 \leqslant n-m \leqslant N_3$

当 $n - N_2 \geqslant N_0$ 且 $n - N_3 \leqslant N_1$ 时，y(n)有非 0 值，此时 $N_0 + N_2 \leqslant n \leqslant N_1 + N_3$。

所以 $N_4 = N_0 + N_2$，$N_5 = N_1 + N_3$。

</details>

#### 教材 7-35 ｜ 反卷积求h(n)及系统框图
> **归类** 5.1
> **原图** `images/tb/fig7-7-20.png`
> **页码** 242

**题干**

某地质勘探测试设备给出的发射信号 $x(n) = \delta(n) + \dfrac{1}{2}\delta(n-1)$，接收回波信号 $y(n) = \left(\dfrac{1}{2}\right)^{n} u(n)$，若地层反射特性的系统函数以 h(n)表示，且满足 $y(n) = h(n) * x(n)$。

(1)求 h(n)；(2)以延时、相加、倍乘运算为基本单元，试画出系统框图。

<details><summary>📖 解答</summary>

解：已知 $x(n) = \delta(n) + \dfrac{1}{2}\delta(n-1)$，$y(n) = \left(\dfrac{1}{2}\right)^{n} u(n)$。

（1）方法一：根据 $h(n) = \left[y(n) - \sum\limits_{m=0}^{n-1} h(m)x(n-m)\right] / x(0)$，可得：

$$h(0) = 1,\quad h(1) = 0,\quad h(2) = \left(\frac{1}{2}\right)^{2},\quad h(3) = 0,\quad h(4) = \left(\frac{1}{2}\right)^{4},\ \cdots$$

归纳得

$$h(n) = \begin{cases} 0, & n\text{ 为奇数} \\ \left(\dfrac{1}{2}\right)^{n}, & n\text{ 为偶数} \end{cases}$$

方法二：$h(n) + \dfrac{1}{2}h(n-1) = \left(\dfrac{1}{2}\right)^{n} u(n)$，特征根为 $-\dfrac{1}{2}$，可令全响应

$$h(n) = B\left(-\frac{1}{2}\right)^{n} + \left(\frac{1}{2}\right)^{n+1}, \quad n \geqslant 0$$

将 $h(0) = 1$ 代入，得 $B = \dfrac{1}{2}$

所以 $h(n) = \dfrac{1}{2}\left[\left(-\dfrac{1}{2}\right)^{n} + \left(\dfrac{1}{2}\right)^{n}\right] = \begin{cases} \left(\dfrac{1}{2}\right)^{n}, & n\text{ 为偶数} \\ 0, & n\text{ 为奇数} \end{cases}$

（2）特征根：$\alpha_1 = \dfrac{1}{2}, \alpha_2 = -\dfrac{1}{2}$，对应差分方程 $y(n) - \dfrac{1}{4}y(n-2) = x(n)$

其系统框图如图 7-20 所示。

#### 名校 7-6 ｜ 差分方程的递推求解
> **归类** 5.1
> **出处** 中国科学院 2005 研
> **页码** 245

**题干**

由差分方程 $y(n) - 0.5y(n-1) = \sum\limits_{k=0}^{4}\left[x(n-k) - 2x(n-k-1)\right]$ 和非零起始条件 $y(-1) = 1$ 表示的离散时间因果系统，当系统输入 $x(n) = \delta(n)$ 时，试用递推算法求：

（1）该系统的零状态响应 $y_{zs}(n)$（至少计算出前 6 个序列值）；

（2）该系统的零输入响应 $y_{zi}(n)$（至少计算出前 4 个序列值）。

<details><summary>📖 解答</summary>

解：（1）零状态响应满足

$$y_{zs}(n) = 0.5y_{zs}(n-1) + x(n) - x(n-1) - x(n-2) - x(n-3) - x(n-4) - 2x(n-5)$$

且有 $y_{zs}(n) = 0, n < 0$。

当输入 $x(n) = \delta(n)$ 时，递推计算得

$$y_{zs}(0) = 1,\ y_{zs}(1) = -\frac{1}{2},\ y_{zs}(2) = -\frac{5}{4},\ y_{zs}(3) = -\frac{13}{8},\ y_{zs}(4) = -\frac{29}{16},\ y_{zs}(5) = -\frac{93}{32}$$

（2）零输入响应满足 $y_{zi}(n) = 0.5y_{zi}(n-1)$，且 $y_{zi}(-1) = 1$

递推计算得

$$y_{zi}(0) = \frac{1}{2},\ y_{zi}(1) = \frac{1}{4},\ y_{zi}(2) = \frac{1}{8},\ y_{zi}(3) = \frac{1}{16}$$

</details>
