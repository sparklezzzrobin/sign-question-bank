# 信号与系统 · 刷题掌握系统

武汉大学 807 / 936《信号与系统》2013–2026 真题（144 题）的分类刷题与掌握度追踪工具。纯静态本地页面，**双击即用、完全离线**。

### 外观风格（🎨 按钮）

顶栏 🎨 按钮可切换两套设计语言 × 明暗，共四种组合，选择会记忆：

- **暖纸 · Claude 风**（默认）：燕麦色纸感底、赤陶橙点缀、衬线字体标题、暖色细边框——致敬 claude.ai 的设计语言；
- **冷灰 · 现代风**：冷灰底 + 靛蓝点缀的简洁风格。

## 快速开始

双击根目录的 **`启动刷题系统.cmd`**（或直接打开 `app/index.html`）。

> 启动脚本会自动探测 Chrome / Edge 并打开页面——它**不依赖系统的 .html 文件关联**（部分电脑的 .html 关联指向已废弃的 IE，会导致"双击没反应"）。也可以手动：右键 `app/index.html` → 打开方式 → Chrome。

## 功能

| 视图 | 说明 |
| :-- | :-- |
| ✍️ 刷题 | 题卡流式列表（单列居中），支持按来源筛选：**历年真题 / 教材课后习题 / 名校考研真题 / 课件补充**。每张卡：题干（公式已渲染）、原图（可点开放大）、折叠解析、PDF 直链 |
| 🔥 掌握热力图 | GitHub 风格全局掌握图，**仅统计历年真题**。**年份×题号矩阵**与**按专题平铺**两种模式，点击格子跳到对应题目 |
| 🗺️ 全库热力图 | **全体题库**（真题＋教材习题＋名校真题＋课件补充）按专题分块的掌握热力图，点击格子跳到对应题目 |
| 📊 统计 | 各状态计数、总掌握率、六专题进度条、按日打卡热力图、数据备份管理 |

### 📚 教材习题库（郑君里《信号与系统》第3版教辅）

题库除历年真题外，还在持续收入**郑君里教辅的课后习题详解与名校考研真题详解**（源自 `pdf/郑君里…详解.pdf`，共 12 章）：

- 题卡以橙色"教材 2-15 / 中山大学 2010 研"徽章标识，底部有"教辅详解 · pN"按钮可直达教辅 PDF 对应页；
- 章节映射：第 1/2/3+5/4/7+8/12 章分别归入专题一~六；超出武大考纲的第 6/9/10/11 章自动归入新增的**专题七~十（拓展专题）**；
- 转录产物在 `教材习题库/第XX章_*.md`（LaTeX 逐题转录，插图裁剪至 `images/tb/`），修改后运行 `cd app/tools && npm run build` 重新生成题库数据（如浏览器缓存了旧数据，把 `index.html` 里 `questions.js?v=N` 的版本号 +1）；
- 插图批量裁剪：`python 教材习题库/extract_figures.py <章号> <页码列表>`（按"图 N-M"标签自动定位、跨页自动拼接）。

### 标记题目

每张卡片底部：

- **不会 🔴 / 不熟 🟡 / 掌握 🟢**：三选一，再点一次取消；
- **☆ 收藏**：独立开关，与掌握状态互不影响；
- 卡片左边缘颜色随掌握状态变化，扫一眼即知错题分布。

### 🤖 AI 讲解（DeepSeek）

每张题卡**右上角有「🤖 AI」按钮**，点开右侧对话抽屉：

- AI 已自动读取**本题题干与参考解析**（含完整 LaTeX），直接问思路、要逐步推导、让它检验你的解法、出同类题都行；
- 首次使用点抽屉里 **⚙️** 填 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 申请），可选 `deepseek-flash`（V4.1 Flash，快，推荐日常）或 `deepseek-v4-pro`（V4 Pro，更强，难题深挖）；
- **深度思考**：V4 系模型默认先推理再回答，思考过程会实时显示在回答上方的「💭 深度思考中」折叠块里（完成后可展开回看）；简单问题想快点出答案，可在 ⚙️ 里关掉深度思考；
- **输出方式**：默认流式逐字输出；如果挂了代理导致长时间收不到数据（60 秒无数据会自动中断并提示），改成「整段返回」即可绕过；
- Key 只存本机浏览器，请求由页面**直连 api.deepseek.com 官方接口**，不经过任何第三方；
- 每道题的对话记录分开保存，随「导出备份」一起带走；发送中可点「⏹ 停止」中断生成。

### 侧栏宽度

左侧导航栏与内容区之间有**拖拽分隔条**：拖动调宽（180–520px，自动记忆），双击复位；悬停在被截断的小节名上也会显示完整名称。

### 筛选与搜索

筛选条支持：状态（不会/不熟/掌握/未标/收藏）、年份、关键词搜索（标题＋题干）。左侧栏点击专题或小节可缩小范围，"错题重刷"推荐用法：状态选 **不会** → 逐题攻克 → 改标 **掌握**。

### 数据存储与备份

- 做题记录保存在**本浏览器** localStorage 中，换浏览器 / 换电脑 / 清缓存前请先在「统计 → 数据管理」**导出备份**（JSON 文件），到时**导入**即可恢复；
- 暗色 / 明亮主题偏好会自动记忆。

## 题目图片说明

- 部分年份原图切片缺失（2025 年 6 张、早年存档若干），卡片会显示"原图缺失"提示，请点卡片上的 **原卷 PDF** 按钮对照原卷；
- 少量图片为题库图床外链，需联网加载。

## 更新题库后重建数据

题卡数据由 `专题刷题库/*.md` 构建而来。修改题库 Markdown 后：

```bash
cd app/tools
npm install        # 仅首次
npm run build      # 重新生成 app/data/questions.js 并打印对账报告
```

构建报告会输出：题卡总数与解析覆盖数、缺图清单、公式渲染报错清单，可据此检查题库改动。

```
└── README.md               # 本文件
```
