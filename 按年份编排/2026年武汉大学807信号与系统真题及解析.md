## 第一题 · 冲激配平法与微分方程初值跳变
* **分类**：`模块四 拉氏变换与S域分析` > `4.1.2 节点/回路法求解全响应`
* **题干**：LTI 系统，微分方程 $y''(t) + 2y'(t) + y(t) = f''(t) + f'(t) + f(t)$，初始状态为 0，$f(t) = \delta(t)$。求 $y(0^+), y'(0^+)$ 及 $y(t)$。
* **解析**：
  法一（冲激配平法）：设 $y''(t) = a\delta''(t) + b\delta'(t) + c\delta(t)$，对比系数得 $a=1, b=-1, c=2$，故 $y(0^+) = b = -1, y'(0^+) = c = 2$。
  法二（S 域法）：$Y(s) = rac{s^2+s+1}{s^2+2s+1} = 1 - rac{1}{s+1} + rac{1}{(s+1)^2}$，反变换得 $y(t) = \delta(t) - e^{-t}u(t) + te^{-t}u(t)$。

* **分类**：`模块二 连续与离散时域响应` > `2.2.2 多级级联系统逆推与复合系统响应`
* **题干**：LTI 级联系统，已知 $h_2[n], h_3[n] = u[n]-u[n-2]$，总冲激响应如图。求 $h_1[n]$ 及输入为 $\delta[n]-\delta[n-1]$ 时的响应。
* **解析**：$h[n] = h_1[n] * h_2[n] * h_3[n]$，利用不进位乘法与长除法反卷积解出 $h_1[n] = \{1, 1, 2, 1, 1\}$。
